Violating rule 0 is unacceptable and irreversible for the owner's GitHub profile. STOP before writing any such line.

## 1. Never start a file with admonition before header

**Wrong:**
```md
!!! tip "Title"
    text
# Header
```

**Correct:**
```md
# Header
> intro text
!!! tip "Title"
    text
```

**Check:** `head -n1` must be `# `, never `!!!`.

**Fixed in:** 02-speaking-survival, 04-horen-survival, 05-lesen-survival, 02-exam-writing, 02-opposites

## 2. Never use inline · with 3+ items on one line

**Wrong:** `**Prost!** (cheers) · **zahlen** (the bill) · **die Karte** (the menu) · **kaputt** ...`

!!! tip "Bonus everyday words"

## 7. Never use `**Example conversation` as plain bold + blockquote

**Wrong:**
```md
**Example conversation:
> "Line 1"
> "Line 2"
```

**Correct:**
```md
!!! example "Example conversation"
    - "Line 1"
    - "Line 2"
```

Each dialogue must be separate bullet with blank line, not `> "` blockquote without separation.

**Indentation trap:** 4-space indented bullets or quotes are ONLY valid inside `!!!`, `???`, or `===` containers. Anywhere else they render as grey code blocks with visible `**` and `>` marks:

```md
**Example flow:**

    - "**Weißt du,** ..."   <- renders as CODE, broken
```

```md
!!! example "Example flow"
    - "**Weißt du,** ..."   <- renders as bullets, correct
```

**Check:** build the site, then scan rendered HTML for `<pre>` blocks whose text starts with `-`, `*`, `>`, or `**` - every hit is this bug.

**Fixed in:** 06-daily-conversations 8 blocks + 2 indented-code traps (Example flow, Example)

## 12. Never join two summary statements on one line - one row per line

Two `**Label:**` statements on one paragraph line render as a single run-on line. Each statement gets its own bullet so each renders as its own row.

**Wrong:**

```md
**Total core:** Parts 01-05. **Application:** Parts 06-09.
```

**Correct:**

```md
- **Total core:** Parts 01-05.
- **Application:** Parts 06-09.
```

Tables and example sentences are exempt (a table row IS a row; `Ich **habe** ... **gelernt**.` is one sentence). This rule is only for standalone `**Label:** ... **Label:** ...` paragraph lines.

**Check:** `grep -rn "^\*\*[^*]*:\*\*" docs/ --include="*.md"` - every hit with 2+ bold phrases on one line must be split into bullets.

**Fixed in:** docs/index.md (2 lines), levels/A1/index.md, levels/A2/index.md

## 13. Use mkdocs-material visual features - it is the documenting system

This book renders with [mkdocs-material](https://squidfunk.github.io/mkdocs-material/). Use its enabled features to help visually instead of plain bold or blockquotes. What is enabled in `mkdocs.yml`: admonitions, details, content tabs, task lists, mark/highlight, keys, emoji. Mermaid is installed but BANNED by owner decision - never use diagrams of any kind (no mermaid, no ASCII diagrams, no flowcharts). Tables and lists carry structure instead.

**Wrong:**

```md
**Warning: never say "zu Hause gekommen".**
```

**Correct:** admonition matching the message type:

```md
!!! warning "Direction vs location"
    **nach Hause** = direction (Ich gehe nach Hause). **zu Hause** = location (Ich bin zu Hause).
```

Guidance:

- Callouts (tip, warning, danger, note, success, example) as `!!! type "Title"` - never as `**Bold**` + `>` quote (see rule 7).
- Alternatives side by side (textbook vs spoken, formal vs du, Perfekt vs Präteritum) as content tabs, not stacked quotes.
- Checklists (exam day, self-check) as task lists `- [ ]`, not plain bullets, when the learner must tick them off.
- Collapsible extras (`???`) for answers and deep dives so pages stay scannable.
- `==mark==` to highlight the one decisive word in a sentence, not whole-sentence bold.
- Respect existing bans: NO emoji in `09-Fluency-Speaking/` files, no grid-cards hack (rule 5), no puzzles/games in fluency content.

**Check:** `grep -rn '^\*\*[A-Z][^*]*\*\*$' docs/ --include="*.md"` - a lone bold line is usually a callout that should be an admonition.

**Applies from:** 2026-09-04 (A2 build).

## 14. Links carry the exact location - never file-only when a section is meant

A cross-reference that means a section must deep-link to its header anchor (`file.md#section-anchor`), never just the file. Old `:25` line numbers are dead (lines drift) - map each to the nearest header and verify the anchor id in the built HTML.

**Wrong:** `[07-grammar-essentials.md](07-grammar-essentials.md)` for Chance/Zeit/Lust + zu.

**Correct:** `[07-grammar-essentials.md §25](07-grammar-essentials.md#25-zu-infinitiv-the-chance-to-drive-chance-zeit-lust-zu-verb)`.

**Check:** every relative link target must resolve, every `#anchor` must exist as an `id` in the built page. `mkdocs build --strict` must pass with zero warnings. No `](...) §N` pattern may remain: `grep -rnE "\]\([^)]+\) §?[0-9]+" docs/ --include="*.md" | grep -v "#"` must print nothing.
