# Hidden Master Formatting Rules - for AI agents only

> This file prevents every formatting mistake we fixed in 2026-09-03/04. Read this before you create or edit ANY markdown file in this vault or in deutsch-book. Not for learner.

---

## 1. Never start a file with admonition before header

**Wrong:**
```md
!!! tip "Title"
    text
# Header
```

**Correct:**
```md
# Header
> intro text
!!! tip "Title"
    text
```

**Check:** `head -n1` must be `# `, never `!!!`.

**Fixed in:** 02-speaking-survival, 04-horen-survival, 05-lesen-survival, 02-exam-writing, 02-opposites

## 2. Never use inline · with 3+ items on one line

**Wrong:** `**Prost!** (cheers) · **zahlen** (the bill) · **die Karte** (the menu) · **kaputt** ...`

**Correct:** bullet list inside admonition:
```md
!!! tip "Bonus everyday words"
    - **Prost!** (cheers)
    - **zahlen** (the bill)
    - **die Karte** (the menu)
```

**Check:** `grep -c "·" line >=3 and not table`

**Fixed in:** 06-daily-conversations Bonus everyday words, 08-Practice-Lab logs left as is

## 3. Never leave **Header:** without blank line before bullet list

**Wrong:**
```md
**Examples:**
- "I need..."
```

**Correct:**
```md
**Examples:**

- "I need..."
```

Must have blank line between `**Header:**` and first `-`.

**Fixed in:** 02-speaking-survival Examples (3 bullets), 14 files total via comprehensive_fix

## 4. Never use `> **Title` + `> -` blockquote list

**Wrong:**
```md
> **The daily trio:**
> - Item 1
> - Item 2
```

**Correct:**
```md
!!! example "The daily trio"
    - Item 1
    - Item 2
```

**Fixed in:** 07-grammar-essentials Focused practice sheets (7 items), 06-daily-conversations daily trio (3), 04-da-wo-compounds Key distinction (2), 02-06-negation Quick test, 03-06-future A2 reality, 03-01-conjugations dauern/mögen

## 5. Never use grid cards with `---` inline that renders as single line

**Wrong:** `<div class="grid cards" markdown>` with `:material-numeric-1-circle:` icons that are invalid or missing blank lines around `---`

**Correct:** Use simple table or numbered list for 5 changes:
```md
1. **Drop the -e** - ich habe → **ich hab**
2. **mal = magic word** - *Kannst du mir mal helfen?*
```

**Fixed in:** 06-daily-conversations Spoken German Cheat Sheet (5 changes grid -> numbered list), 07-exam-cheat-sheet Hören/Lesen/Sprechen grid -> table

## 6. Never leave `**Bold` without closing `**`

**Wrong:** `**Bonus: everyday words that replace the textbook word`

**Correct:** `**Bonus: everyday words that replace the textbook word**` or `!!! tip "Bonus: ..."`

**Check:** `grep -n "^\*\*[^*]*[^*]$"` - odd count

**Fixed in:** 06-daily-conversations 8 lines (Nämlich, Da … hin split, etc.)

---

## 7. Never use `**Example conversation` as plain bold + blockquote

**Wrong:**
```md
**Example conversation:
> "Line 1"
> "Line 2"
```

**Correct:**
```md
!!! example "Example conversation"
    - "Line 1"
    - "Line 2"
```

Each dialogue must be separate bullet with blank line, not `> "` blockquote without separation.

**Fixed in:** 06-daily-conversations 8 blocks

---

## 8. Always separate `### Rule` headings with `---`

**Wrong:** `### Rule 1` table immediately followed by `### Rule 2` with no separator - renders as single paragraph

**Correct:**
```md
### Rule 1: ...
| table |
---
### Rule 2: ...
```

**Fixed in:** 06-daily-conversations 10 Rules
