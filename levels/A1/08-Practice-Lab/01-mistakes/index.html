    Mistake Notebook (A1) - spaced re-test log

    Rule: every error gets logged with the RULE (not just the fix). We re-test on the dates in the right column. [PASS] = produced correctly from memory, then strike through.

    NEVER count as errors: (1) umlauts typed as ae/oe/ue, (2) noun capitalization. Both are keyboard/typing habits, not language gaps. Only real language errors are logged.

    Re-tests are RANDOM: shuffled order, random timing - never M1 to M13 in sequence, never a fixed day schedule.

    M1 - Dative after gehören (CASE)

    • Rule: gehören (belong to) ALWAYS takes the Dativ object.
    • Wrong: Das Buch gehört mich.
    • Right: Das Buch gehört mir. (ich→mir, du→dir, er→ihm, sie→ihr, wir→uns…)
    • Re-test: Day+1 [PASS] (Das Buch gehört ihm - dative correct!), Day+3, Day+7
    • Session re-test: [FAIL] "Das Geschenk gehört meine Mutter" → meiner Mutter (Dativ). RE-OPEN. Session [PASS] "Das Geschenk gehört meiner Mutter" (Dativ correct). RESOLVED.

    M2 - weil-clause word order (SENTENCE BUILDING)

    • Rule: weil (because) is a subordinating conjunction → the conjugated verb goes to the END of that clause. Main clause keeps position 2.
    • Wrong: Es regnet, deswegen ich … zu Hause.
    • Right: Weil es regnet, bleibe ich zu Hause. (bleiben = stay; zu Hause = at home)
    • Re-test: Day+1 [FAIL] then [PASS] on follow-up drill (weil es spät ist / weil sie müde ist / weil das Kind klein ist - all verb-final). RESOLVED; confirm Day+3.
    • Session re-test: [FAIL] wrote "weil dem Kind ist klein" → verb not final ("klein ist") AND subject wrong case (das Kind, not dem). RE-OPEN. Session [FAIL+]: "weil wir gehen nach Hause" → verb not final, must be "weil wir nach Hause gehen". Session [PASS] "Wir helfen ihm, weil das Kind klein ist" (verb-final + nominative subject). RESOLVED. Session [FAIL]: "weil es regnet ist" → extra verb; weil clause = one verb at end: "weil es regnet".

    M3 - Noun capitalization (FORM) - STRUCK per AGENTS.md §1 (capitalization of nouns is a keyboard habit, NEVER an error, never log/fail)

    • Rule: ALL nouns are capitalized (das Buch, die Mutter, das Kind, das Haus in "nach Hause"). Pronouns ich/du/er/sie/es/wir/ihr stay LOWERCASE even at sentence start - only Sie (formal you) / Ihnen capitalize.
    • Re-test: ongoing / every production block
    • Day+1 re-test: [FAIL] noun caps still missing: Buch, Bett, Haus, Kind, Softwareentwickler, Frau. (Note: ich/du/sie/wir are correctly lowercase - only NOUNS capitalize.) User confirms rule known - typing habit only.
    • DECISION (2026-08-27): capitalization is a typing habit, NOT a language gap. Never count it as an error, never log it. CLOSED.
    • [STRUCK] per AGENTS.md §1 noun capitalization is NOT an error - Wasser/Bett lowercase must not be logged or failed. M3 closed.

    M4 - Spelling (FORM)

    • wir (not we), heute (not huete), gehört (not gehort)
    • Tip: type umlauts as ae/oe/ue - I read "gehoert" fine, but learn the real keys: Option+u then a/o/u (Mac), or Alt+e.
    • Day+1 re-test: [FAIL] gehort→gehört, mude→müde - but user confirmed they KNOW umlauts; only the keyboard lacks the keys. NOT a learning gap. CLOSED (keyboard-only). I read ae/oe/ue as ä/ö/ü.
    • DECISION (2026-08-27): umlaut typing is a keyboard limitation, NOT a language gap. Never count it as an error, never log it.

    M5 - Statement vs. Question + ich/Sie (SENTENCE BUILDING)

    • Rule: A statement about YOURSELF starts with Ich + verb-2 (Ich wohne …). A question starts verb-first (Wohnen Sie …?). Never use Sie for yourself.
    • Wrong: Wo wohnen Sie und was sind Sie von Beruf? (answered the prompt as a question, used Sie)
    • Right: Ich wohne in [Stadt]. Ich bin Softwareentwickler. / Ich arbeite bei Check24 als Softwareentwickler.
    • Re-test: Day+1 [PASS] (Ich bin softwareentwickler - correct statement, no Sie-for-self), Day+3

    M6 - Present-tense conjugation / subject-verb agreement (SENTENCE BUILDING)

    • Rule: verb ending MUST match the subject: ich -e | du -st | er/sie/es -t | wir -en | ihr -t | sie/Sie -en
    • Wrong: das Geschenk gehoren (→gehört); die Blumen gefallt (→gefallen); sie antwroten (→antwortet)
    • Right: es gehört / sie (pl) gehören · es gefällt / sie (pl) gefallen · sie (she) antwortet
    • Re-test: Day+1 [PASS] (Wir geben, Sie hilft, Ich gehe, Ich bin - all endings correct), Day+2, Day+4
    • Note (Day+1 drill): "sie … kaufen" resurfaced (should be kauft, sie = -t). RESURFACED under load - keep watching -t for er/sie/es. Re-check Day+2.
    • Session re-test: [FAIL] "sie helfen dem Kind" (she) → sie hilft (she = sg, -t). RE-OPEN. Also "wir kann" → wir können (we = pl -en).

    M9 - Dative ARTICLES for nouns (CASE)

    • Rule: dative article = dem (m/nt) · der (f) · den (pl). After dative verbs, the NOUN object takes these, not accusative das/die.
    • Wrong: sie hilft das Kind · wir geben die Frau die Blumen
    • Right: sie hilft dem Kind · wir geben der Frau die Blumen
    • Re-test: Day+1 [PASS] (Sie hilft dem Kind / Wir geben der Frau die Blume - dative articles correct), Day+3
    • Session re-test: [FAIL] wrote "Sie hilft den Kind" (den = Akk) → must be dem Kind (Dativ nt). RE-OPEN. Session [PASS] "Sie hilft dem Mann" (dem Mann, dative m) - RESOLVED. Session [FAIL]: "Sie danken lehrer" → dem Lehrer (dative article after danken).

    M8 - du / ihr / Sie split (CONCEPT)

    • Rule: English "you" = 3 German words. du (sg informal, -st) · ihr (pl informal "you guys", -t) · Sie (formal, -en).
    • Wrong: treating "ihr" prompt as "du" → du dankst uns
    • Right: Ihr dankt uns (plural you) · Du dankst (sg) · Sie danken (formal)
    • Re-test: Day+1, Day+3

    M7 - False friends: denken vs. danken (VOCAB)

    • Rule: denken = to think · danken = to thank (danken + DATIVE)
    • Wrong: wir denken ihr (meant "we thank her")
    • Right: wir danken ihr
    • Re-test: Day+1, Day+3
    • Update: denken confusion GONE after danken drill. Residue = person/ending (ihr vs du, sie→-t) → folded into M6.
    • Session re-test: [FAIL→typo] "ihr denkt uns" was a typo (denkt/dankt) → not a language gap. M7 RESOLVED.

    M10 - Direction prepositions: ins Bett / nach Hause (VOCAB/CASE)

    • Rule: "go to bed" = ins Bett gehen (in + das → ins). "go home" = nach Hause (NOT zu Hause - that means "at home").
    • Wrong: Ich gehe nach bett. / Ich gehe zu hause.
    • Right: Ich gehe ins Bett. / Ich gehe nach Hause.
    • Re-test: Day+1 [FAIL] (wrote "nach bett" and later "zu hause"); user learned the nach/zu distinction (see 05-prepositions.md §5c). RESOLVED - keep an eye on production.
    • Session re-test: [RE-OPEN] wrote "in bett" - lost the ins (= in + das) contraction. Also wrote "ich gehe zu Hause" for "go home" → must be nach Hause (movement); zu Hause = "at home". (Capital B is noun-cap → NOT counted per AGENTS §1.) Session [PASS] "ich gehe ins bett um 10 Uhr" (ins Bett correct). RESOLVED.

    M11 - Adjective endings (A1, later topic)

    • Rule: adjective takes ending by case/article: after der/die/das → -e (das kleine Buch); after ein/kein → matches der-word (ein kleines Kind); no article → strong (kaltes Wasser).
    • Re-test: Day+1 [PASS] (Das kleine Kind trinkt Wasser / Wir lesen das alte Buch / Er kauft das teure Auto - adjective -e after das correct). RESOLVED for der/die/das. Follow-up: ein/kein variant (ein kleines Kind) - drill Day+2.
    • Session re-test: [FAIL] then [PASS] "Ein kleines Kind trinkt Wasser" (Kind = neuter → ein kleines). ein/kein variant RESOLVED.

    M12 - Accusative vs Dative article AFTER the verb (CASE)

    • Rule: lesen / kaufen / trinken / brauchen / sehen / finden / holen + AKK (das/die/den); helfen / gehören / danken / antworten / gefallen + DAT (dem/der/den).
    • Wrong: wir lesen dem Buch (→ das Buch)
    • Right: wir lesen das Buch · wir helfen dem Kind
    • Re-test: Day+1 [FAIL] then [PASS] on focused drill (Sie hilft dem Mann / Wir danken der Frau / Er antwortet dem Kind / Das Geschenk gehört der Mutter - all dative articles correct). RESOLVED.

    M13 - Main-clause verb position 2 (SENTENCE BUILDING)

    • Rule: in a main clause the finite verb is in position 2 (right after the subject): Subj + Verb + Rest. NOT at the end.
    • Wrong: Sie das Auto kauft.
    • Right: Sie kauft das Auto. (Sie = 1, kauft = 2)
    • Note: opposite of a weil-clause, where the verb goes LAST (M2). Main = V2, sub-clause = V-last.
    • Re-test: Day+1 [FAIL] then [PASS] on re-drill (Er liest das Buch / Wir kaufen das Auto / Sie trinken Wasser - verb position 2). RESOLVED. Session [FAIL] "sie viel arbeitet" → sie arbeitet viel (V2). RE-OPEN. Session [PASS] multiple correct V2 productions (Der Mann liest ein Buch; Ich lerne Deutsch; Wir gehen nach Hause...). RESOLVED.

    M14 - Dative PRONOUNS after dative verbs (CASE)

    • Rule: dative verbs (helfen, danken, gehören, antworten, gefallen) take the DATIVE pronoun: ich→mir, du→dir, er→ihm, sie→ihr, es→ihm, wir→uns, ihr→euch, sie/Sie→ihnen/Ihnen.
    • Wrong: Ich helfe dich. (dich = accusative)
    • Right: Ich helfe dir. (du → dir)
    • Re-test: session [FAIL] (wrote "dich"); Day+1, Day+3. Session [PASS] "ich helfe ihr" (sie→ihr, dative) - correct. RESOLVED.

    M15 - Two-way prepositions: LOCATION = Dative (CASE)

    • Rule: two-way prepositions (in, an, auf, neben, vor, hinter, über, unter, zwischen) take Dativ when there is NO movement (static location), Akkusativ only with movement (direction).
    • Wrong: Die Apotheke ist neben die Bank. (ist = location → needs Dativ)
    • Right: Die Apotheke ist neben der Bank. (neben + Dativ f = der)
    • Re-test: session [FAIL] (neben die Bank); also "in die Kuche" → in der Küche (in + location = Dativ). Day+1, Day+3

    M16 - ein-article GENDER (no adjective)

    • Rule: ein-words match the noun's gender/case: das Ticket (nt, Akk) → ein Ticket; der Mann (m, Akk) → einen Mann; die Frau (f, Akk) → eine Frau.
    • Wrong: Ich möchte einen Ticket kaufen.
    • Right: Ich möchte ein Ticket kaufen.
    • Re-test: session [FAIL] (einen Ticket → ein Ticket; auch "kein Zeit" → keine Zeit, die Zeit = f). Session [FAIL+]: "eine Ticket" → ein Ticket (Ticket = nt). Session [PASS] "Ich möchte einen Kaffee" / "ein Ticket" (ein/en gender correct). RESOLVED. Session [FAIL]: "ein fahrkarte" → eine Fahrkarte (Fahrkarte = f). RE-OPEN.

    M17 - haben (have) vs heben (lift) (VOCAB)

    • Rule: haben = to have; heben = to lift (different word). "I have" = Ich habe.
    • Wrong: Ich hebe kein Zeit. (meant "I have")
    • Right: Ich habe keine Zeit.
    • Re-test: session [FAIL]; session [PASS] "ich habe keine zeit" (haben correct). RESOLVED. Day+1, Day+3

    M18 - Nominative SUBJECT case (CASE)

    • Rule: the SUBJECT of a clause is always Nominative: das Kind (nt) / der Mann (m) / die Frau (f). Never dative (dem/der/den) for a subject.
    • Wrong: weil dem Kind ist klein (dem = dative, but Kind is the subject)
    • Right: weil das Kind klein ist
    • Re-test: session [FAIL]; Day+1, Day+3

    M19 - scheinen (shine) vs breit (wide) (VOCAB)

    • Rule: die Sonne scheint = the sun shines; breit = wide (wrong word here).
    • Wrong: Die Sonne ist breit.
    • Right: Die Sonne scheint.
    • Re-test: session [FAIL]; Day+1, Day+3

    M20 - zu Hause (at home), not bei Hause (PREP/VOCAB)

    • Rule: "at home" = zu Hause. "bei" means at/with (a person), not "at home".
    • Wrong: Ich bleibe bei Hause.
    • Right: Ich bleibe zu Hause.
    • Re-test: session [FAIL]; Day+1, Day+3

    M21 - Mir ist kalt (I am cold) (CONSTRUCTION)

    • Rule: "I am cold" = Mir ist kalt (dative mir + ist). "Ich habe kalt" is wrong.
    • Wrong: Ich habe kalt.
    • Right: Mir ist kalt.
    • Re-test: session [FAIL]; Day+1, Day+3

    M22 - Adjective ending after ein-WORDS by gender (CASE/ADJ)

    • Rule: after ein/kein/eine/ein the adjective ending follows the noun's gender: eine neue Wohnung (f, -e) · ein neues Kind (nt, -es) · einen neuen Mann (m Akk, -en).
    • Wrong: Wir suchen eine neues Wohnung.
    • Right: Wir suchen eine neue Wohnung.
    • Re-test: session [FAIL]; also "ein teuer Auto" → ein teures Auto (nt -es). Also "ein teuers Auto" → ein teures Auto. Day+1, Day+3

    M23 - suchen + Akkusativ (no "für") (VOCAB)

    • Rule: suchen (look for) takes a direct accusative object - NO preposition "für". "I look for X" = ich suche X.
    • Wrong: Wir suchen für eine Wohnung.
    • Right: Wir suchen eine Wohnung.
    • Re-test: session [FAIL]; Day+1, Day+3

    M24 - Modal verb + INFINITIVE (not conjugated) (VERB FORM)

    • Rule: after a modal verb (muss, kann, möchte, will, darf, soll) the second verb stays in the INFINITIVE: ich muss arbeiten (not arbeite).
    • Wrong: ich muss heute arbeite
    • Right: ich muss heute arbeiten
    • Re-test: session [FAIL]; Day+1, Day+3

    M25 - kein/keine PLURAL (ARTICLE/NUMBER)

    • Rule: plural negative = keine. Singular neuter negative = kein (not keine). Kinder (pl) → keine Kinder; Geld (nt) → kein Geld.
    • Wrong: Ich habe kein Kinder. / Ich habe keine Geld.
    • Right: Ich habe keine Kinder. / Ich habe kein Geld.
    • Re-test: session [FAIL] (kein Kinder → keine Kinder; auch keine Geld → kein Geld, nt). Day+1, Day+3

    M26 - Definite article GENDER (der/die/das)

    • Rule: der (m) · die (f) · das (nt). Bahnhof = der Bahnhof (m) → "Wo ist der Bahnhof?", not die.
    • Wrong: Wo ist die Bahnhof?
    • Right: Wo ist der Bahnhof?
    • Re-test: session [FAIL]; session [PASS] "Wo ist der bahnhof" (der Bahnhof correct). RESOLVED. Day+1, Day+3

    M27 - Comparatives: groß → größer (WORD FORM)

    • Rule: comparative = stem + -er, and groß umlauts its vowel: groß → größer (= plain-letter "grosser"). The error is the missing -er suffix, NOT the umlaut/ß (keyboard).
    • Wrong: Mein Bruder ist grosse als ich. (no -er)
    • Right: Mein Bruder ist grosser als ich. (= größer)
    • Re-test: session [FAIL] (grosse → grosser, missing -er); also "mere teuer" → teurer. Day+1, Day+3

    M28 - Geschenk (noun) vs geschenkt (Partizip) (VOCAB/WORD FORM)

    • Rule: das Geschenk = the gift (noun). geschenkt = given (Partizip of schenken). Don't use geschenkt as the noun.
    • Wrong: das geschenkt gehört meiner Mutter
    • Right: das Geschenk gehört meiner Mutter
    • Re-test: session [FAIL]; Day+1, Day+3

    M29 - im = in + dem (PREP + ARTICLE contraction)

    • Rule: with masculine/neuter places "in dem" contracts to im. Iran = der Iran (m) → im Iran (not "in Iran").
    • Wrong: meine Eltern wohnen in Iran
