# Visual Standard - which element for which content (READ BEFORE WRITING ANY LESSON)

> Hidden master rule for AI agents only, like `.RULES-FORMATTING.md`. This file decides
> EXACTLY which mkdocs-material element carries which type of content, so every book,
> part, and chapter looks like it came from one publisher. No improvising. If a content
> type is not listed here, use the closest row and propose an addition - never invent
> a new pattern silently.
>
> Engine: mkdocs-material with admonitions, details, content tabs, task lists,
> mark/highlight, tables. Mermaid is BANNED (owner decision). Emoji is BANNED in
> `09-Fluency-Speaking/` files.

---

## 1. Page skeleton (every lesson file)

```md
# Title - Topic (A1/A2)

> One-paragraph intro: what this file gives you. No admonition before this header.

---

## 1. Section name

Content...

### 1a. Sub-section (only if needed)

Content...

---

## 2. Next section
```

- Exactly one `#` H1 (the title). Parts are `##`, numbered sections `###`, details `####`.
- `##` shows in the sidebar TOC, `###` shows nested, `####` stays out. Never promote a detail to `###` just for emphasis.

## 2. The element map (the core of this standard)

| # | Content type | Element | Example |
|---|---|---|---|
| 1 | Conjugation / declension / paradigm data | Plain markdown table (`Person | Form | Example`) | dative-verbs mir/dir/ihm tables |
| 2 | Comparisons side by side (der/den/dem, textbook vs spoken) | Plain markdown table | cases-articles N/A/D grids |
| 3 | Alternatives to pick from (friend vs formal letter, du vs Sie, haben vs sein, template versions, scenarios A-G) | Content tabs `=== "Label"` - every tab in ONE set uses the SAME body structure (all tables with the same columns, or all letters, or all lists - never tables in one tab and plain bullets in the next) | exam-writing 5 templates, tenses haben/sein, imperative du/ihr/Sie, survival 5 question types |
| 4 | Letters, messages, rehearsed answers (line-by-line) | Blockquote `>`, one idea per line, hard break (two trailing spaces) at each line end inside one paragraph | exam-writing Einladung, Task 1 answers |
| 5 | Multi-turn dialogues and example conversations | `!!! example "Title"` with one bullet per turn | speaking-survival scenarios, daily-conversations |
| 6 | Advice, tricks, memory hooks | `!!! tip "Title"` | spoken cheat sheet |
| 7 | Traps, common confusions, exam warnings | `!!! warning "Title"` | wegen vs deswegen, du vs Sie |
| 8 | Exam killers (empty box = 0, never do this) and failed attempts | `!!! danger "Title"` (use `!!! failure` only for a shown failed attempt, never for rules) | exam vs daily Sie/full forms |
| 8b | Neutral reference info (format facts, sources, distinctions) | `!!! info "Title"` | Source verified, Key distinction, A2 bridge |
| 9 | Neutral info, format facts | `!!! note "Title"` | present-tense-only, honest footnotes |
| 10 | Milestones, correct results, passed checks | `!!! success "Title"` | only-20-30-words, rehearsed answers |
| 11 | Self-test questions with hidden answers | `??? question "Try yourself"` + table or list inside | time-words quick-check |
| 12 | Answer keys and drill answers (never printed open in drill files) | `??? success "Antworten - expand to check"` | sentences bank, possessive practice |
| 13 | Rehearsal targets (identity script, personal data - cover, recall, check) | `??? success "Cover, recall, then expand to check"` | exam-writing Task 1 data, writing-survival data |
| 14 | Checklists the learner ticks off (exam day, self-check before finishing) | Task list `- [ ]` | cheat-sheet exam-day, tenses self-check |
| 15 | Ordered procedures where sequence matters (do Teil 1 first, strategy steps) | Numbered list `1.` (NEVER task list) | telc-sample-test strategy |
| 16 | The ONE decisive word/morpheme in a sentence | `==mark==` (one decisive token per line, max) | `==ONLY present tense==`, `==Viele Grüße==`, mistake Right-lines |
| 17 | Error vs fix contrast in mistake logs | Wrong line marks the error, Right line marks the fix: `Das Buch gehört ==mich==.` / `Das Buch gehört ==mir==.` | 01-mistakes.md all entries |
| 18 | Cross-references to another file SECTION | `[name §N](path#section-anchor)` - anchor verified in built HTML | essentials §25, tenses §18 |
| 19 | Cross-references to a whole file | `[name.md](path/name.md)` - target must resolve | index tables |
| 20 | File/part index tables | `#` column keeps order numbers; display names WITHOUT `NN-` prefix; link targets KEEP the prefix | `[numbers-dates.md](01-numbers-dates.md)` |
| 21 | Copy-paste verbatim text (forms, code-like content) | Fenced code block (no language tag unless real code) | Task 1 form data alternative, date formats |
| 22 | Key rule sentence inside prose | Bold the rule clause inline, never a lone bold line | `**kein** follows the same endings as **ein / mein**` |
| 23 | Struck content (exactly two uses, nothing else) | `~~text~~` - (a) retired mistake-log entries struck after correct-from-memory production, (b) explicitly wrong example sentences always shown WITH the Correct version beside them | `~~M3 - Noun capitalization~~`, `~~Gestern ich habe Deutsch gelernt.~~` next to Correct |
| 24 | Level index frontmatter | `---` title + level block, ONLY in `levels/X/index.md` (A1, A2, ...) - never in lesson files | A1/A2 index headers |
| 25 | Data tables | Plain `|---|---|` grids, NO column-alignment markers (`:---`), no embedded admonitions inside cells | all conjugation/case tables |

## 3. Choosing between look-alikes (no guessing)

- **Tabs vs stacked sections:** 2+ parallel variants of the SAME idea -> tabs. Sequential steps -> stacked `###` sections.
- **Tabs vs table:** variants with different BODY text (letters, dialogues) -> tabs. Same-row comparisons (der/den/dem) -> table.
- **Collapsible vs visible:** drill answers, keys, rehearsal targets -> collapsible. Reference data (tables, chunks, rules) -> always visible.
- **Task list vs numbered list:** learner ticks completion -> task list. Order matters, no ticking -> numbered list.
- **Mark vs bold:** the single token that decides correctness -> `==mark==`. Terminology, labels, chunks -> `**bold**`.
- **Admonition vs quote:** teaching callout (tip/warning/note/success/example) -> admonition. Quoted content (letter, message, rule citation) -> blockquote.
- **Bullets vs sentence:** `English -> German` drill pairs stay as bullets with hidden answers (row 12), never `A / B` slash-jumbles on one line.

## 4. Hard bans (from owner decisions, repeated here so nobody reintroduces them)

- NO mermaid, NO ASCII diagrams, NO flowcharts - tables and lists carry structure.
- NO grid-cards with `---` (renders as one line) - use tables or lists.
- NO emoji in `09-Fluency-Speaking/` files.
- NO en/em dash anywhere - hyphen `-` only.
- NO multiple `#` H1 titles per file (breaks the sidebar TOC).
- NO 4-space indented bullets/quotes outside `!!!`, `???`, `===` containers (renders as grey code block with visible `**`).
- NO `**Label:** ... **Label:** ...` two statements on one line - one bullet per row.
- NO `**Example conversation` as plain bold + blockquote - always `!!! example` with bullets.
- NO bare file paths (`` `file.md` ``) for docs pages - always `[name §N](path#anchor)`.
- NO quizzes, puzzles, games, or trick formats in fluency content.
- NO AI credit, attribution, or branding anywhere (see `AGENTS.md`).
- NO footnotes (extension not enabled - they render as dead text).
- NO `!!! quote` admonitions (quoted content is always `>` blockquote, row 4).
- NO images, math, keyboard-key (`++key++`), critic, or caret markup in lesson files - the book is text + tables.
- NO other admonition types beyond tip/warning/danger/failure/note/success/example/info/question.
- NO nested quotes (`>>`) - separate quote blocks instead.
- NO definition lists - key-value content goes in tables.
- NO explicit `{#anchor}` ids - header anchors auto-generate; use them.
- NO open-by-default details (`???+`) - every collapsible starts closed so answers stay hidden.

## 5. Blockquote line-break rule (the letter fix)

Markdown collapses single newlines inside a quote into one run-on line. Every letter, message, dialogue turn, and template line inside ONE quote paragraph ends with a hard break (two trailing spaces):

```md
> Liebe Anna,··
> ich habe am Samstag Geburtstag.··
> Viele Grüße··
> Hamed
```

(`··` = two spaces.) Safety net in `docs/media/custom.css`: `blockquote p { white-space: pre-line; }`.

## 6. Model lesson (copy this shape for new files)

```md
# Topic - What It Gives You (A2)

> Intro paragraph: what you can do after this file.

---

## 1. Core rule with table

| Case | Form | Example |
|---|---|---|
| ... | ... | ... |

!!! tip "Memory hook"
    One-line hook, then move on.

## 2. Variants (tabs, not stacked sections)

=== "Formal (Sie)"

    > Sehr geehrter Herr Weber,
    > ...
    > Mit freundlichen Grüßen

=== "Friend (du)"

    > Liebe Anna,
    > ...
    > Viele Grüße

## 3. Drill (answers hidden)

- English prompt one.
- English prompt two.

??? success "Antworten - expand to check"

    1. German answer one.
    2. German answer two.

## 4. Checklist (tick off)

- [ ] Check one.
- [ ] Check two.
```

## Checklist before writing any lesson file

- [ ] Skeleton matches section 1 (one H1, `##` parts, `###` numbered sections).
- [ ] Every content block matches a row in the element map (section 2) - nothing improvised.
- [ ] Look-alike choices follow section 3.
- [ ] Zero items from the hard-ban list (section 4).
- [ ] Quote lines end with hard breaks (section 5).
- [ ] Every cross-reference is `[name §N](path#anchor)` with the anchor verified in built HTML.
- [ ] No unlisted elements appear (footnotes, quote admonitions, images, math, keys, aligned tables).
- [ ] `mkdocs build --strict` passes with zero warnings.
