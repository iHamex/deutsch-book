# Mock Test - 33 Questions in 60 Minutes

> Three complete mock tests built from the question bank. Each one is 30 general questions plus 3 questions from your Bundesland. Open the question, answer it on paper, and do not expand the solution until the 60 minutes are over.

[Overview](index.md) | [Mistake log](mistakes.md)

---

## 1. Rules

| Rule | Detail |
|---|---|
| Questions | 33 (30 general + 3 from your Bundesland) |
| Time | 60 minutes |
| Aids | None. No notes, no phone, no dictionary |
| Answers | Write only the letter on a paper answer sheet |
| Pass | 17 correct |
| Review | Only after the timer ends |

!!! danger "The one rule that matters"
    If you open a solution before the timer ends, the mock is worthless. Mark the question, guess if you must, and keep going. A blank answer and a wrong answer score the same.

!!! info "Which state?"
    The tests below use **Bayern**, because that is the state set for Munich. If you write the test in another Bundesland, replace the three Bayern questions with the matching numbers from your state page under [State questions](index.md#6-state-questions).

---

## 2. How to run a mock

1. Put a clock where you can see it and set 60 minutes.
2. Open the first question, read the German, and write the letter on paper.
3. Use the **next** link at the bottom of each page to move on - do not go back.
4. At 60 minutes, stop writing, even if you have blanks.
5. Open the answer key for that test and mark every answer right or wrong.
6. Log every wrong answer in the [mistake log](mistakes.md) with the reason, not just the correct letter.

!!! tip "Paper first, screen second"
    Reading on screen makes recognition feel easier than it is. Writing the letter on paper adds the small physical step that the real test also has.

## 4. Score

| Score | Result | Next step |
|---|---|---|
| 33 | Perfect | Take the next test in three days |
| 30-32 | Very strong | Review only the missed questions |
| 17-29 | Pass | Log every miss and re-test after two days |
| 0-16 | Not yet | Return to the question sets, one set per day, then try again |

!!! warning "A pass is not mastery"
    17/33 is the legal pass mark, not your goal. Aim for 30+ consistently. The extra margin protects you from a bad day, a distracting room, or one unfamiliar wording.

---

## 5. Review routine

1. Mark every wrong answer in the [mistake log](mistakes.md).
2. For each miss, write the correct sentence in German, not just the letter.
3. Say the correct sentence aloud three times.
4. Re-test the same 33 questions after two days.
5. Take the next mock test on a different day, not the same evening.

!!! tip "Make more tests"
    Pick every 10th general question starting at a different number (for example 3, 13, 23 ... 293) and add three state questions you have not seen recently. The 60-minute rules stay the same.
