## 3. At the doctor - Beim Arzt

| German | English |
|--------|---------|
| Was fehlt Ihnen? | What's wrong? |
| Was ist los? | What's the matter? |
| Wo tut es weh? | Where does it hurt? |
| Ich habe Kopfschmerzen. | I have a headache. |
| Seit wann haben Sie das? | Since when have you had that? |
| Seit drei Tagen. | Since three days. |
| Haben Sie Fieber? | Do you have a fever? |
| Haben Sie Schnupfen? | Do you have a runny nose? |
| Haben Sie Husten? | Do you have a cough? |
| Sind Sie erkältet? | Do you have a cold? |
| Ich schaue mir das mal an. | Let me take a look. |
| Öffnen Sie bitte den Mund. | Please open your mouth. |
| Atmen Sie bitte ein und aus. | Please breathe in and out. |
| Das ist eine Erkältung. | That's a cold. |
| Das ist keine Grippe. | That's not the flu. |
| Sie brauchen Bettruhe. | You need bed rest. |
| Sie müssen drei Tage im Bett bleiben. | You have to stay in bed for three days. |
| Ich schreibe Ihnen ein Rezept. | I'll write you a prescription. |
| Gehen Sie zur Apotheke. | Go to the pharmacy. |
| Kommen Sie in einer Woche wieder. | Come back in a week. |
| Wie geht es Ihnen jetzt? | How are you now? |
| Besser. Vielen Dank! | Better. Thank you very much! |

## 4. At the pharmacy - In der Apotheke

| German | English |
|--------|---------|
| Guten Tag, ich brauche etwas gegen Kopfschmerzen. | Hello, I need something for a headache. |
| Haben Sie ein Rezept? | Do you have a prescription? |
| Ja, hier ist das Rezept. | Yes, here is the prescription. |
| Was ist das gegen? | What is that for? |
| Das ist gegen Kopfschmerzen. | That's for headaches. |
| Wie oft muss ich das nehmen? | How often do I have to take this? |
| Dreimal am Tag. | Three times a day. |
| Vor oder nach dem Essen? | Before or after eating? |
| Vor dem Essen. | Before eating. |
| Nach dem Essen. | After eating. |
| Muss ich das kühlen? | Do I have to refrigerate it? |
| Nein, Zimmertemperatur. | No, room temperature. |
| Wie viele Tabletten? | How many tablets? |
| Dreimal zwei Tabletten. | Three times two tablets. |
| Danke, auf Wiedersehen. | Thank you, goodbye. |
