# Appointments and Making Plans - Termine und Verabredungen

> Making, confirming, canceling, and rescheduling appointments. One of the most practical A1 skills - you'll use this at the doctor, the Amt, and with friends.

## 2. Making appointments - Termine vereinbaren

### Formal (Sie)

| German | English |
|--------|---------|
| Können Sie mir einen Termin geben? | Can you give me an appointment? |
| Wann hätte ich einen Termin? | When could I have an appointment? |
| Wann passt es Ihnen? | When suits you? |
| Wann können Sie kommen? | When can you come? |
| Ich bräuchte einen Termin. | I would need an appointment. |
| Ich möchte einen Termin vereinbaren. | I would like to schedule an appointment. |
| Ich möchte einen Termin machen. | I would like to make an appointment. |
| Wann ist der nächste freie Termin? | When is the next available appointment? |
| Haben Sie morgen Zeit? | Do you have time tomorrow? |
| Geht es am Montag? | Does Monday work? |
| Können wir uns am Dienstag treffen? | Can we meet on Tuesday? |
| Wie wäre es mit Mittwoch? | How about Wednesday? |
| Ich schlage Freitag vor. | I suggest Friday. |
| Das passt mir. | That suits me. |
| Das passt mir nicht. | That doesn't suit me. |
| Das geht leider nicht. | That unfortunately doesn't work. |
| Können wir es verschieben? | Can we postpone it? |
| Können wir einen anderen Termin machen? | Can we make a different appointment? |
| Ich komme um 10 Uhr. | I'll come at 10 o'clock. |
| Ich bin um 14 Uhr da. | I'll be there at 2 o'clock. |

### Informal (du)

| German | English |
|--------|---------|
| Hast du am Samstag Zeit? | Do you have time on Saturday? |
| Wollen wir uns treffen? | Do we want to meet? |
| Wann passt es dir? | When suits you? |
| Wann kannst du kommen? | When can you come? |
| Können wir uns am Freitag treffen? | Can we meet on Friday? |
| Wie wäre es am Samstag? | How about Saturday? |
| Lass uns am Sonntag treffen. | Let's meet on Sunday. |
| Ich schlage Samstag vor. | I suggest Saturday. |
| Das passt mir super! | That suits me great! |
| Das passt mir leider nicht. | That unfortunately doesn't suit me. |
| Sorry, ich kann leider nicht. | Sorry, I unfortunately can't. |
| Lass uns einen anderen Tag machen. | Let's pick another day. |
| Ich bin um 15 Uhr frei. | I'm free at 3 o'clock. |
| Ich komme um 18 Uhr. | I'll come at 6 o'clock. |

## 4. Canceling and rescheduling - Absagen und Umplanen

### Canceling

| German | English |
|--------|---------|
| Es tut mir leid, ich kann nicht. | I'm sorry, I can't. |
| Ich muss absagen. | I have to cancel. |
| Ich muss meinen Termin absagen. | I have to cancel my appointment. |
| Leider kann ich nicht kommen. | Unfortunately I can't come. |
| Ich bin leider verhindert. | Unfortunately I'm unavailable. |
| Ich habe leider keine Zeit. | Unfortunately I don't have time. |
| Es geht leider nicht. | Unfortunately it doesn't work. |
| Das tut mir leid. | I'm sorry about that. |

### Rescheduling

| German | English |
|--------|---------|
| Können wir umplanen? | Can we reschedule? |
| Können wir einen anderen Termin machen? | Can we make a different appointment? |
| Können wir es verschieben? | Can we postpone it? |
| Lass uns einen anderen Tag finden. | Let's find another day. |
| Wie wäre es nächste Woche? | How about next week? |
| Geht es am Montag? | Does Monday work? |
| Ich schlage Dienstag vor. | I suggest Tuesday. |

| German | English |
|--------|---------|
| Sehr geehrte Damen und Herren, | Dear Sir or Madam, |

## 6. A1 Exam writing templates - Schreibvorlagen

=== "A: Invite a friend (café / park)"

    ```
    Liebe Anna,

    Können wir uns am Samstag treffen? Um 15 Uhr im Café?
    Schreib mir bitte, ob es dir passt.

    Viele Grüße
    Hamed
    ```

=== "B: Formal meeting request (Amt / doctor)"

    ```
    Sehr geehrter Herr Weber,

    Könnten wir uns nächste Woche treffen? Ich hätte gerne einen Termin.
    Wann passt es Ihnen?

    Mit freundlichen Grüßen
    Hamed Okhovvat
    ```

=== "C: Cancel appointment (sick)"

    ```
    Sehr geehrte Damen und Herren,

    Es tut mir leid, ich muss meinen Termin am Freitag absagen.
    Ich bin leider krank. Können wir einen neuen Termin machen?

    Mit freundlichen Grüßen
    Hamed Okhovvat
    ```

=== "D: Confirm / reject invitation"

    ```
    Liebe Fatima,

    vielen Dank für die Einladung! Das passt mir super.
    Ich komme am Samstag um 18 Uhr.

    Viele Grüße
    Hamed
    ```

!!! tip "Exam writing rules"
    1. German date format: **21.09.2026** or **21. September 2026** — NEVER 09/21/2026
    2. Time before place: *Wir treffen uns am Samstag um 15 Uhr im Café.*
    3. Every box filled, message signed. Empty = 0 points.
