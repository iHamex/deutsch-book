## 4. At the restaurant - Im Restaurant

| German | English |
|--------|---------|
| Einen Tisch für zwei, bitte. | A table for two, please. |
| Die Speisekarte, bitte. | The menu, please. |
| Was können Sie empfehlen? | What can you recommend? |
| Ich möchte gern bestellen. | I would like to order. |
| Ich möchte gern ... | I would like ... |
| Ich nehme ... | I'll have ... |
| Was ist die Tagesuppe? | What is the soup of the day? |
| Haben Sie eine Speisekarte auf Englisch? | Do you have a menu in English? |
| Kann ich die Speisekarte sehen? | Can I see the menu? |
| Ich bin Vegetarier. | I am a vegetarian. |
| Ich esse kein Fleisch. | I don't eat meat. |
| Ich bin allergisch gegen Nüsse. | I am allergic to nuts. |
| Die Rechnung, bitte. | The bill, please. |
| Stimmt so. | Keep the change. |
| Das Essen ist sehr gut. | The food is very good. |
| Das Essen ist lecker. | The food is delicious. |
| Das schmeckt gut. | That tastes good. |
| Das schmeckt nicht. | That doesn't taste good. |
| Noch ein Bier, bitte. | Another beer, please. |
| Noch einen Kaffee, bitte. | Another coffee, please. |
