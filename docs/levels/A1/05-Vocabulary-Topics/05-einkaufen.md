## 4. Shopping phrases - Einkaufsphaesen

| German | English |
|--------|---------|
| Kann ich Ihnen helfen? | Can I help you? |
| Ich schaue mich nur um. | I'm just looking. |
| Ich suche eine Jacke. | I'm looking for a jacket. |
| Haben Sie das in grün? | Do you have that in green? |
| Haben Sie das in einer anderen Größe? | Do you have that in a different size? |
| Kann ich das anprobieren? | Can I try that on? |
| Die Umkleidekabine ist dort. | The fitting room is there. |
| Das passt gut. | That fits well. |
| Das passt nicht. | That doesn't fit. |
| Das ist zu groß. | That's too big. |
| Das ist zu klein. | That's too small. |
| Das gefällt mir. | I like that. |
| Das gefällt mir nicht. | I don't like that. |
| Wie viel kostet das? | How much does that cost? |
| Das ist zu teuer. | That's too expensive. |
| Das ist billig. | That's cheap. |
| Das ist ein Schnäppchen. | That's a bargain. |
| Gibt es einen Rabatt? | Is there a discount? |
| Das ist im Angebot. | That's on sale. |
| Ich nehme das. | I'll take that. |
| Kann ich mit Karte zahlen? | Can I pay by card? |
| Bar oder Karte? | Cash or card? |
| Ich zahle bar. | I'll pay cash. |
| Ich zahle mit Karte. | I'll pay by card. |
| Haben Sie eine Tüte? | Do you have a bag? |
| Danke, auf Wiedersehen. | Thank you, goodbye. |
