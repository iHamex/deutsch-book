## 6. Asking strangers - Fremde ansprechen

| German | English |
|--------|---------|
| Entschuldigung! | Excuse me! |
| Kann ich Sie etwas fragen? | May I ask you something? |
| Wo ist hier...? | Where is...? |
| Wie komme ich zu...? | How do I get to...? |
| Gehen Sie geradeaus. | Go straight ahead. |
| Biegen Sie links ab. | Turn left. |
| Biegen Sie rechts ab. | Turn right. |
| Das ist in der Nähe. | That's nearby. |
| Das ist weit weg. | That's far away. |
| Das ist um die Ecke. | That's around the corner. |
| Das ist gegenüber. | That's opposite. |
| Das ist auf der linken Seite. | That's on the left side. |

| Das ist neben dem Park. | That's next to the park. |
