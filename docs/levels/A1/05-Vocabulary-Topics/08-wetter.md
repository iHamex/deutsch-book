# Weather - Wetter

> Talking about the weather is a German national pastime. Master these phrases and you'll never run out of small talk.

---

|--------|---------|

## 2. How's the weather? - Wie ist das Wetter?

| German | English |
|--------|---------|
| Wie ist das Wetter heute? | How's the weather today? |
| Wie ist das Wetter morgen? | How's the weather tomorrow? |
| Wie war das Wetter gestern? | How was the weather yesterday? |
| Wie wird das Wetter? | How will the weather be? |

---

## 3. Describing the weather - Wetter beschreiben

| German | English |
|--------|---------|
| Es ist sonnig. | It's sunny. |
| Es ist bewölkt. | It's cloudy. |
| Es ist regnerisch. | It's rainy. |
| Es ist windig. | It's windy. |
| Es ist neblig. | It's foggy. |
| Es schneit. | It's snowing. |
| Es regnet. | It's raining. |
| Es gewittert. | It's thundering. |
| Es ist warm. | It's warm. |
| Es ist heiß. | It's hot. |
| Es ist kalt. | It's cold. |
| Es ist kühl. | It's cool. |
| Es ist frisch. | It's fresh. |
| Es ist angenehm. | It's pleasant. |
| Es ist trocken. | It's dry. |

## 4. Temperature - Temperatur

| German | English |
|--------|---------|
| Wie viel Grad sind es? | How many degrees is it? |
| Es sind 25 Grad. | It's 25 degrees. |
| Es sind minus 5 Grad. | It's minus 5 degrees. |
| Es sind 30 Grad im Schatten. | It's 30 degrees in the shade. |
| Die Temperatur steigt. | The temperature is rising. |
| Die Temperatur sinkt. | The temperature is dropping. |

## 8. Weather phrases for small talk - Wettergespraeche

| German | English |
|--------|---------|
| Schönwetter heute! | Beautiful weather today! |
| Das ist ja schön! | That's nice! |
| Das wird besser! | It'll get better! |
| Das wird schlechter! | It'll get worse! |
| Hoffentlich wird es besser. | Hopefully it'll get better. |
| Es ist perfekt zum Ausgehen. | It's perfect for going out. |
| Ich nehme einen Regenschirm mit. | I'll take an umbrella with me. |
| Ich brauche eine Sonnenbrille. | I need sunglasses. |
| Ich brauche einen Mantel. | I need a coat. |
| Das ist typisches Herbstwetter. | That's typical autumn weather. |

---

## 9. Forecast vocabulary - Vorhersage

| German | English |
|--------|---------|
| die Wettervorhersage | weather forecast |
| die Prognose | forecast |
| Morgen wird es sonnig. | Tomorrow it will be sunny. |
| Morgen wird es regnen. | Tomorrow it will rain. |
| Morgen wird es schneien. | Tomorrow it will snow. |
| Am Nachmittag wird es gewittern. | In the afternoon there will be thunderstorms. |
| Das Risiko von Regen ist 50 %. | The risk of rain is 50 %. |
| Es wird trocken bleiben. | It will stay dry. |
