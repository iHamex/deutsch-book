## 3. At the train station - Am Bahnhof

| German | English |
|--------|---------|
| Wo ist der Bahnhof? | Where is the train station? |
| Wo ist der Bahnsteig? | Where is the platform? |
| Von welchem Bahnsteig fährt der Zug nach Berlin? | From which platform does the train to Berlin depart? |
| Wann fährt der nächste Zug? | When does the next train leave? |
| Wann kommt der Zug an? | When does the train arrive? |
| Der Zug hat Verspätung. | The train is delayed. |
| Der Zug fällt aus. | The train is cancelled. |
| Muss ich umsteigen? | Do I have to change trains? |
| Wo muss ich umsteigen? | Where do I have to change? |
| Wie lange dauert die Fahrt? | How long does the journey take? |
| Die Fahrt dauert zwei Stunden. | The journey takes two hours. |
| Ich brauche ein Einzelfahrkarte. | I need a single ticket. |
| Ich brauche eine Hin- und Rückfahrkarte. | I need a return ticket. |
| Wie viel kostet eine Fahrkarte nach Berlin? | How much is a ticket to Berlin? |
| Wo ist der Fahrkartenautomat? | Where is the ticket machine? |
| Die Abfahrt ist um 14:30. | Departure is at 2:30 PM. |
| Die Ankunft ist um 16:45. | Arrival is at 4:45 PM. |

| Nehmen Sie die zweite Straße rechts. | Take the second street on the right. |
| Die Straße heißt Hauptstraße. | The street is called Hauptstrasse. |
| Die Straße heißt Erika-Mann-Straße. | The street is called Erika-Mann-Strasse. |
| Die Ampel ist rot. | The traffic light is red. |
| Die Ampel ist grün. | The traffic light is green. |
| Die Ampel ist gelb. | The traffic light is yellow. |
| Die Kreuzung ist hier. | The intersection is here. |
| Das ist in der Nähe. | That's nearby. |
| Das ist weit weg. | That's far away. |
| Das ist gegenüber. | That's across the street. |
| Das ist auf der linken Seite. | That's on the left side. |
| Das ist auf der rechten Seite. | That's on the right side. |

| Das ist zwischen zwei Häusern. | That's between two houses. |
