# Question Words (Fragewörter) - A1

> Ask questions. Cases matter: **wer** (NOM), **wen** (AKK), **wem** (DAT).

## Table
| Word | Meaning | Case | Example |
| --- | --- | --- | --- |
| wer | who | NOM | Wer ist das? |
| wen | whom | AKK | Wen siehst du? |
| wem | whom | DAT | Wem hilfst du? |
| was | what | NOM/AKK | Was machst du? / Was hast du? |
| wo | where | - | Wo wohnst du? |
| wohin | where to | - | Wohin gehst du? |
| woher | where from | - | Woher kommst du? |
| wann | when | - | Wann kommst du? |
| warum | why | - | Warum lernst du Deutsch? |
| wie | how | - | Wie geht es dir? |
| wie viel | how much | - | Wie viel kostet das? |
| wie viele | how many | - | Wie viele Kinder hast du? |
| welch- | which | N/A/D | Welches Buch liest du? |

## Notes
- **wer / was** start a question → verb in position 2: *Wer **ist** das?*
- **wo** + preposition contracts: womit (wo + mit), wofür (wo + für), worüber. A1 light: *Womit schreibst du?*
- **warum** = formal; spoken A1 also uses *wieso*.

!!! tip "wer vs wen vs wem"
    wer (nom) -> wen (akk) -> wem (dat). Who -> whom -> to whom.
