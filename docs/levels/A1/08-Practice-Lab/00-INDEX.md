## How to use this Lab

1. **After each reading session:** pick 10 sentences from 02-sentences that use the rule you just learned, translate EN -> DE out loud.
2. **After each speaking session:** log new mistakes in 01-mistakes.md in format M1-M13 (rule, wrong, right).
3. **Each session start:** shuffle 3-5 open mistakes from 01-mistakes.md and re-test in random order - never in order.
4. **Strike through:** only after correct production from memory with no hint.

## How this connects

- To fix a mistake: find its file in Parts 01-04 (e.g., M2 weil -> [04-Sentence-Building](../04-Sentence-Building/00-INDEX.md)01-word-order.md)
- After drill: go to [09-Fluency-Speaking](../09-Fluency-Speaking/00-INDEX.md) to use it live.

## Tip

Practice is not reading. Cover German, recall English -> German, say it out loud. If you can say it without looking, it is yours.
