## LEARNING SECTION

### 1. Dative Pronouns

| Nominativ | Dativ |
|-----------|-------|
| ich       | mir   |
| du        | dir   |
| er        | ihm   |
| sie       | ihr   |
| es        | ihm   |
| wir       | uns   |
| ihr       | euch  |
| sie       | ihnen |
| Sie       | Ihnen |

**Common verbs using dative:**

- gehören → Das Buch gehört **mir**
- helfen → Ich helfe **dir**
- gefallen → Das gefällt **mir**
- danken → Ich danke **dir**
- antworten → Er antwortet **mir**

### 2. haben Conjugation

| Pronomen | haben |
|----------|-------|
| ich      | habe  |

**Example sentences:**

- Ich habe ein Auto.
- Du hast eine Schwester.

- Ihr habt recht.

### 5. Negation

- **Kein** = negates nouns (kein Geld, keinen Kaffee)
- **Nicht** = negates verbs/adjectives (nicht gut, nicht kommen)

**Example sentences:**

- Kein → Ich habe kein Geld. / Er trinkt keinen Kaffee.
- Nicht → Das ist nicht gut. / Ich kann nicht kommen.
