# Sentence Skeletons - Bausteine (Your Building Blocks)

> You never build sentences word-by-word. You MATCH a pattern and fill ONE slot.  
> This file is the whole engine: every skeleton you need for the exam + daily life.  
> Add new skeletons here as we discover them in our conversations.

---

## The Golden Rule

!!! tip "Don't translate. Match."
    Every question = one skeleton + one filled slot. The card/topic tells you WHICH skeleton.

---

## 1. The 6 Question Skeletons (telc Part 2 - the whole card game)

| If the word is a... | Skeleton | Example |
|---|---|---|
| person (Lehrer, Chef, Name) | **Wie heißt** ___? | Wie heißt Ihr Lehrer? |
| activity (Trinken, Frühstück, Hobby) | **Was** ___ Sie **gern**? | Was essen Sie gern? |
| place (Wohnort, Stadt) | **Wo** ___ Sie? | Wo wohnen Sie? |
| time (Kurs, Zug, Termin) | **Wann** ___ ___? | Wann beginnt der Kurs? |
| price (Buch, Fahrkarte) | **Wie viel kostet** ___? | Wie viel kostet das Buch? |
| duration (Leben in Deutschland) | **Wie lange** ___ Sie schon ___? | Wie lange wohnen Sie schon hier? |

**Match reflex (card → skeleton):**

- Person → Wie heißt ...?
- Thing/activity → Was ... gern?
- Place → Wo ...?
- Time → Wann ...?
- Money → Wie viel kostet ...?
- Time period → Wie lange ... schon ...?

## 2. The Yes/No Skeletons (any card)

| Skeleton | Example |
|---|---|
| Haben Sie ___? | Haben Sie Kinder? |
| Möchten Sie ___? | Möchten Sie einen Kaffee? |
| Sind Sie ___? | Sind Sie verheiratet? |

Answer: **Ja, ...** / **Nein, ...** + full sentence.

## 4. Request & Reaction Skeletons (telc Part 3)

| Type | Skeleton | Example |
|---|---|---|
| Request | [Thing] + **bitte!** | Ein Glas Wasser, bitte! |
| Request | **Könnte ich bitte** + [thing] + **haben?** | Könnte ich bitte einen Kaffee haben? |
| Request | **Ich möchte bitte** + [thing]. | Ich möchte bitte ein Stück Kuchen. |
| Suggestion | **Lass uns** + [activity]! | Lass uns Obst essen! |
| Offer | **Möchtest du** + [thing]? | Möchtest du einen Kaffee? |
| Accept | **Ja, gerne!** / **Ja, natürlich!** | |
| Decline | **Tut mir leid, ich habe keins.** / **Nein, danke.** | |

## 6. New Skeletons (discovered in practice, 2026-08-27)

| Skeleton | Example |
|---|---|
| **Wissen Sie, wo/wann/wie** + verb at END? | Wissen Sie, wo der Bahnhof ist? |
| **Wie komme ich zum/zur** + place? | Wie komme ich zum Bahnhof? |
| **Es gibt** + noun + in der Nähe. | Es gibt einen Supermarkt in der Nähe. |
| **Ich brauche einen Termin beim** + person. | Ich brauche einen Termin beim Arzt. |
| **Danke, ich habe schon** + past participle. | Danke, ich habe schon gegessen. |
| **Können Sie mir bitte** + verb at END? | Können Sie mir bitte helfen? |
| **Wann ist** + place + **geöffnet**? | Wann ist die Apotheke geöffnet? |

---

## Practice Rule

One skeleton per conversation. Fill every slot out loud / in your head until the
skeleton feels like a reflex. The skeleton is the memory - you only carry 6 of them.
