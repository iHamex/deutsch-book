# Conjugations - COMPLETE A1 Reference (memorize once)

> Every A1 verb = a **Person | Form | Example sentence** table.  
> Format from [dative-verbs.md](02-dative-verbs.md), now with a real German example per row.  
> Case tags: **+AKK** = takes accusative object · **+DAT** = takes dative object · **+DAT +AKK** = person(dative) + thing(accusative).
!!! tip "Learn as chunks"
    Not "helfen = help" but "Ich helfe dir" (+DAT). The +DAT tag tells you the case.

> Log slips in [mistakes.md](../08-Practice-Lab/01-mistakes.md).

## 1. Auxiliaries

### sein (to be)
| Person | Form | Example sentence |
|---|---|---|
| I | Ich bin. | Ich bin Softwareentwickler. |
| you | Du bist. | Du bist mein Freund. |
| he | Er ist. | Er ist mein Chef. |
| she | Sie ist. | Sie ist meine Frau. |
| it | Es ist. | Es ist ein Buch. |
| we | Wir sind. | Wir sind zu Hause. |
| you all | Ihr seid. | Ihr seid Freunde. |
| they | Sie sind. | Sie sind meine Eltern. |
| you (formal) | Sie sind. | Sie sind willkommen. |

### haben (to have, +AKK)
| Person | Form | Example sentence |
|---|---|---|
| I | Ich habe. | Ich habe heute Zeit. |
| you | Du hast. | Du hast eine Schwester. |
| he | Er hat. | Er hat ein Auto. |
| she | Sie hat. | Sie hat zwei Kinder. |
| it | Es hat. | Es hat keine Lust. |
| we | Wir haben. | Wir haben Hunger. |
| you all | Ihr habt. | Ihr habt recht. |
| they | Sie haben. | Sie haben ein Haus. |
| you (formal) | Sie haben. | Sie haben einen Termin. |

### werden (to become, + adjective / noun)
> The third auxiliary! You need it for "to become / get": *Ich werde müde.* (I get tired.)  
> NOT the future tense (that's B1) - at A1 it just means "become".

| Person | Form | Example sentence |
|---|---|---|
| I | Ich werde. | Ich werde müde. (I'm getting tired.) |
| you | Du wirst. | Du wirst groß. |
| he | Er wird. | Er wird Lehrer. (He's becoming a teacher.) |
| she | Sie wird. | Sie wird 30. (She's turning 30.) |
| it | Es wird. | Es wird kalt. (It's getting cold.) |
| we | Wir werden. | Wir werden müde. |
| you all | Ihr werdet. | Ihr werdet alt. |
| they | Sie werden. | Sie werden glücklich. |
| you (formal) | Sie werden. | Sie werden nicht krank. |

> **Chunk to memorize:** *Es wird kalt.* / *Ich werde müde.* / *Das wird teuer.* (That'll be expensive.)

### lassen (to let / to leave / to have something done)
| Person | Form | Example sentence |
|---|---|---|
| I | Ich lasse. | Lass uns gehen! (Let's go!) |
| you | Du lässt. | Lass mich in Ruhe! (Leave me alone!) |
| he | Er lässt. | Er lässt das Fenster offen. (He leaves the window open.) |
| she | Sie lässt. | Sie lässt sich photographieren. (She has herself photographed.) |
| it | Es lässt. | Das lässt sich nicht ändern. (That can't be changed.) |
| we | Wir lassen. | Wir lassen das so. (We'll leave it like that.) |
| you all | Ihr lasst. | Lasst uns spielen! (Let's play!) |

**Key chunks with lassen:**

- Lass uns + infinitive! = Let's...! (Lass uns gehen!/Lass uns essen!)
- Lassen Sie mich... = Let me... (Lassen Sie mich nachdenken.)
- Ich lasse mir + infinitive = I have something done (Ich lasse mir die Haare schneiden.)
