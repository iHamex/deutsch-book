# Bank and Money (A2)

> A2 vocabulary for 2 telc themes: Konto/Überweisung, Geldautomaten, Preise/Rechnungen.

---

## 1. Konto - Account

| German | English | Example |
| --- | --- | --- |
| das Konto | account | Ich eröffne **ein** Konto. |
| das Girokonto | checking account | Ich habe **ein** Girokonto. |
| das Sparkonto | savings account | Ich habe **ein** Sparkonto. |
| die Bank | bank | Ich gehe **zur** Bank. |
| der Geldautomat | ATM | Ich gehe **zum** Geldautomaten. |
| die Banküberweisung | bank transfer | Ich mache **eine** Überweisung. |
| die Überweisung | transfer | Ich schicke **eine** Überweisung. |
| der Kontostand | account balance | Wie ist **der** Kontostand? |
| die EC-Karte | debit card | Ich bezahle **mit der** EC-Karte. |
| die Kreditkarte | credit card | Ich bezahle **mit der** Kreditkarte. |
| die PIN | PIN | Ich kenne **meine** PIN nicht. |
| das Bargeld | cash | Ich brauche **Bargeld**. |
| die Gebühr | fee | Die **Gebühr** ist 5 Euro. |

## 3. Bank sentences

| German | English |
| --- | --- |
| Ich möchte ein Konto eröffnen. | I would like to open an account. |
| Wie viel Geld möchten Sie abheben? | How much money would you like to withdraw? |
| Können Sie mir eine Überweisung machen? | Can you make a transfer for me? |
| Wie hoch ist mein Kontostand? | What is my account balance? |
| Ich möchte 200 Euro abheben. | I would like to withdraw 200 euros. |
| Kann ich mit Karte zahlen? | Can I pay by card? |
| Haben Sie Kleingeld? | Do you have change? |
| Die Gebühr ist 5 Euro. | The fee is 5 euros. |

!!! tip "Chunk to memorize"
    *Ich möchte 200 Euro abheben.* / *Kann ich mit Karte zahlen?* / *Wie hoch ist mein Kontostand?*

## 4. Bei der Post - At the post office (telc theme)

| German | English | Example |
| --- | --- | --- |
| die Post | post office | Ich gehe **zur** Post. |
| der Brief | letter | Ich schicke **einen** Brief. |
| die Postkarte | postcard | Ich schicke **eine** Postkarte. |
| das Paket | parcel | Ich schicke **ein** Paket. |
| das Päckchen | small parcel | **Das** Päckchen ist leicht. |
| die Briefmarke | stamp | Ich brauche **eine** Briefmarke. |
| die Sendung | shipment | Wo ist **meine** Sendung? |
| die Sendungsnummer | tracking number | Ich habe **eine** Sendungsnummer. |
| der Empfänger | recipient | **Der** Empfänger wohnt in Berlin. |
| der Absender | sender | **Der** Absender bin ich. |
| das Porto | postage | Was kostet **das** Porto? |
| die Zustellung | delivery | **Die** Zustellung dauert 3 Tage. |
| die Packstation | parcel locker | Ich hole mein Paket **an der** Packstation. |
| abholen | to pick up | Ich **hole** das Paket **ab**. |
| einschreiben | to send registered | Ich schicke den Brief **eingeschrieben**. |

### Post sentences

| German | English |
| --- | --- | --- |
| Ich möchte ein Paket nach Teheran schicken. | I would like to send a parcel to Tehran. |
| Was kostet das Porto? | What does the postage cost? |
| Ich brauche zwei Briefmarken. | I need two stamps. |
| Wie lange dauert die Lieferung? | How long does the delivery take? |
| Kann ich das Paket per Einschreiben schicken? | Can I send the parcel by registered mail? |
| Wo kann ich das Paket abholen? | Where can I pick up the parcel? |
| Die Sendung ist unterwegs. | The shipment is on its way. |

!!! tip "Chunk to memorize"
    *Ich möchte ein Paket schicken.* / *Was kostet das Porto?* / *Wo kann ich das Paket abholen?*
