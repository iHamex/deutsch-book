## 2. Farben und Größen - Colors and Sizes

| German | English | German | English |
| --- | --- | --- | --- |
| rot | red | blau | blue |
| grün | green | gelb | yellow |
| schwarz | black | weiß | white |
| braun | brown | grau | gray |
| lila/violett | purple | orange | orange |
| rosa/pink | pink | hell | light |
| dunkel | dark | bunt | colorful |

| Size | German | Example |
| --- | --- | --- |
| S (small) | klein | Das ist mir **zu klein**. |
| M (medium) | mittel | Größe **M** ist gut. |
| L (large) | groß | Haben Sie das in **groß**? |
| XL (extra large) | sehr groß | Das ist mir **zu groß**. |

### Shopping sentences

| German | English |
| --- | --- |
| Kann ich das anprobieren? | Can I try this on? |
| Haben Sie das in einer anderen Farbe? | Do you have this in another color? |
| Haben Sie das in einer anderen Größe? | Do you have this in another size? |
| Das passt mir nicht. | That doesn't fit me. |
| Das ist mir zu klein/groß. | That is too small/big for me. |
| Wie viel kostet das? | How much does that cost? |
| Das ist zu teuer. | That is too expensive. |
| Gibt es einen Rabatt? | Is there a discount? |
| Ich nehme das. | I'll take that. |
| Kann ich mit Karte zahlen? | Can I pay by card? |

## 3. Café und Restaurant

| German | English | Example |
| --- | --- | --- |
| die Speisekarte | menu | Ich hätte gern **die** Speisekarte. |
| die Rechnung | bill | Kann ich **die** Rechnung haben? |
| das Trinkgeld | tip | Ich gebe **10%** Trinkgeld. |
| die Reservierung | reservation | Ich habe **eine** Reservierung. |
| das Frühstück | breakfast | Ich esse **das** Frühstück um 7 Uhr. |
| das Mittagessen | lunch | **Das** Mittagessen ist um 12 Uhr. |
| das Abendessen | dinner | **Das** Abendessen ist um 19 Uhr. |

| das Getränk | drink | Ich hätte gern **ein** Getränk. |

### Restaurant sentences

| German | English |
| --- | --- |
| Einen Tisch für zwei Personen, bitte. | A table for two, please. |
| Ich hätte gern die Speisekarte. | I would like the menu. |
| Was können Sie empfehlen? | What can you recommend? |
| Ich bin allergisch gegen... | I am allergic to... |
| Die Rechnung, bitte. | The bill, please. |
| Das Essen war sehr lecker. | The food was very delicious. |
| Das Fleisch ist nicht gut. | The meat is not good. |
| Ich möchte das umtauschen. | I would like to exchange that. |

## 4. Reklamation - Complaint

| German | English |
| --- | --- |
| Das ist kaputt. | That is broken. |
| Das ist nicht in Ordnung. | That is not okay. |
| Ich möchte das umtauschen. | I would like to exchange that. |
| Können Sie das reparieren? | Can you repair that? |
| Ich möchte mein Geld zurück. | I would like my money back. |
| Die Garantie ist noch gültig. | The warranty is still valid. |

!!! tip "Chunk to memorize"
    *Kann ich das anprobieren?* / *Die Rechnung, bitte.* / *Das ist mir zu teuer.*

| Theme | Key chunk | English |
| --- | --- | --- |

| Restaurant | Die Rechnung, bitte. | The bill, please. |
