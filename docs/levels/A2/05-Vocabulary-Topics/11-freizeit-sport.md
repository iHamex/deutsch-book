# Leisure, Sports, and Festivals (A2)

> A2 vocabulary for 3 telc themes: Hobbys, Sport, Feste und Einladungen. Learn the chunks the way Germans say them - with the right verb (spielen, machen, gehen), not as isolated nouns.

---

## 1. Hobbys - say it with the right verb

> German does NOT say "I do reading" (Ich mache Lesen). It says: Ich lese gern / Ich gehe schwimmen / Ich spiele Fußball. Learn the whole chunk.

| German chunk | English | Activity type |
| --- | --- | --- |
| Ich lese gern. | I like to read. | verb + gern |
| Ich schreibe gern. | I like to write. | verb + gern |
| Ich koche gern. | I like to cook. | verb + gern |
| Ich fotografiere gern. | I like to take photos. | verb + gern |
| Ich male gern. | I like to paint. | verb + gern |
| Ich wandere gern. | I like to hike. | verb + gern |
| Ich gehe gern schwimmen. | I like to go swimming. | gehen + verb |
| Ich gehe gern joggen. | I like to go jogging. | gehen + verb |
| Ich gehe gern wandern. | I like to go hiking. | gehen + verb |
| Ich fahre gern Fahrrad. | I like to cycle. | fahren + noun |
| Ich sammle Briefmarken. | I collect stamps. | verb + object |
| Ich spiele gern Fußball. | I like to play football. | spielen + noun |
| Ich spiele gern Schach. | I like to play chess. | spielen + noun |
| Ich mache gern Musik. | I like to make music. | machen + noun |
| Ich mache gern Sport. | I like to do sport. | machen + noun |
| Ich höre gern Musik. | I like to listen to music. | hören + noun |
| Ich sehe gern Filme. | I like to watch films. | sehen + noun |
| Ich treffe gern Freunde. | I like to meet friends. | treffen + noun |

| Hobby noun | English | Example |
| --- | --- | --- |
| das Hobby | hobby | Mein Hobby ist Kochen. |
| die Freizeit | free time | In meiner Freizeit lese ich. |
| die Musik | music | Ich höre gern Musik. |
| die Gartenarbeit | gardening | Ich mache gern Gartenarbeit. |
| das Reisen | travelling | Ich reise gern. |

!!! warning "drei Verb-Gruppen - never 'Ich mache gern Lesen'"
    - Hobby mit eigenem Verb: **Ich lese gern.** (not: Ich mache gern Lesen)
    - Bewegung: **Ich gehe schwimmen / joggen / wandern.**
    - Sportspiele: **Ich spiele Fußball / Tennis / Schach.**
    - Only a few take machen: Sport, Musik, Yoga, Fotos, Gartenarbeit.

!!! tip "Chunk to memorize"
    *In meiner Freizeit lese ich gern und gehe schwimmen.* (In my free time I like to read and go swimming.)

## 5. Einladungen - Invitations (accept, decline, arrange)

| German | English | Function |
| --- | --- | --- |
| Hast du Lust, mitzukommen? | Do you feel like coming along? | invite |
| Ich lade dich ein. | I invite you. | invite |
| Gern, ich komme! | Gladly, I will come! | accept |
| Das klingt gut! | That sounds good! | accept |
| Tut mir leid, ich kann nicht. | Sorry, I cannot. | decline |
| Ich habe schon etwas vor. | I already have plans. | decline (soft) |
| Können wir das verschieben? | Can we postpone that? | rearrange |
| Wann passt es dir? | When suits you? | arrange |
| Ich bringe einen Salat mit. | I will bring a salad. | offer |
| Bis dann! | See you then! | end |

!!! warning "absagen vs verschieben"
    absagen = cancel completely (Ich muss leider absagen). verschieben = move to another time (Können wir auf nächste Woche verschieben?). Do not mix them.
