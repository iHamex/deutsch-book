# Housing and Moving (A2)

> A2 vocabulary for 2 telc themes: Wohnungssuche, Einrichtung, Nachbarn, Mängel melden.

---

## 1. Wohnung - Apartment

| German | English | Example |
| --- | --- | --- |
| die Wohnung | apartment | Ich suche **eine** Wohnung. |
| das Zimmer | room | Ich brauche **ein** Zimmer. |
| die Küche | kitchen | Die **Küche** ist klein. |
| das Badezimmer | bathroom | Das **Badezimmer** ist neu. |
| das Schlafzimmer | bedroom | Das **Schlafzimmer** ist geräumig. |
| das Wohnzimmer | living room | Das **Wohnzimmer** ist hell. |
| der Balkon | balcony | Ich habe **einen** Balkon. |
| der Keller | basement | Im **Keller** ist mein Fahrrad. |
| der Dachboden | attic | Auf dem **Dachboden** ist viel Platz. |
| der Garten | garden | Wir haben **einen** Garten. |
| der Flur | hallway | Im **Flur** steht ein Schrank. |
| die Etage | floor (level) | Ich wohne in der dritten **Etage**. |
| der Aufzug | elevator | Der **Aufzug** funktioniert nicht. |
| die Treppe | stairs | Ich gehe die **Treppe** hoch. |

## 3. Mängel - Problems

| German | English | Example |
| --- | --- | --- |
| das Loch | hole | Im Boden ist ein **Loch**. |
| der Riss | crack | In der Wand ist ein **Riss**. |
| der Schaden | damage | Es gibt **einen** Schaden. |
| der Mangel | defect/problem | Ich melde **einen** Mangel. |
| undicht | leaking | Die Toilette ist **undicht**. |
| kaputt | broken | Der Wasserhahn ist **kaputt**. |
| laut | loud | Die Nachbarn sind **laut**. |
| kalt | cold | Im Winter ist es **kalt**. |
| schimmelig | moldy | Die Wand ist **schimmelig**. |

### Mängel sentences

| German | English |
| --- | --- |
| Der Wasserhahn ist kaputt. | The faucet is broken. |
| Die Toilette ist undicht. | The toilet is leaking. |
| In der Wand ist ein Riss. | There is a crack in the wall. |
| Ich muss den Vermieter anrufen. | I have to call the landlord. |
| Können Sie das reparieren? | Can you repair that? |
| Das muss schnell repariert werden. | That must be repaired quickly. |

## 4. Nachbarn - Neighbors

| German | English | Example |
| --- | --- | --- |
| der Nachbar | neighbor (m) | Mein **Nachbar** ist nett. |
| die Nachbarin | neighbor (f) | Meine **Nachbarin** ist laut. |
| die Nachbarschaft | neighborhood | Die **Nachbarschaft** ist ruhig. |
| der Lärm | noise | Ich habe Angst vor **dem** Lärm. |
| ruhig | quiet | Die Straße ist **ruhig**. |
| laut | loud | Die Musik ist zu **laut**. |
| die Ruhe | silence/peace | Ich brauche **die** Ruhe. |
| die Hausordnung | house rules | Ich halte mich an **die** Hausordnung. |

### Neighbor sentences

| German | English |
| --- | --- |
| Meine Nachbarin ist zu laut. | My neighbor is too loud. |
| Können Sie bitte leiser sein? | Can you please be quieter? |
| Ich muss die Ruhe bewahren. | I have to stay calm. |
| Die Hausordnung sagt: Nachtruhe ab 22 Uhr. | The house rules say: quiet after 10 PM. |

!!! tip "Chunk to memorize"
    *Der Wasserhahn ist kaputt. Können Sie das reparieren?* / *Meine Nachbarin ist zu laut.*
