# Media, Weather, and Appointments (A2)

> A2 vocabulary for 3 telc themes: Mediennutzung, Wetter im Detail, Termine/Verabredungen. Learn nouns with articles and verbs with prepositions - chunks, not lists.

---

## 2. Wetter - Weather

| German | English | Example |
| --- | --- | --- |
| das Wetter | weather | Wie ist **das** Wetter heute? |
| die Temperatur | temperature | **Die** Temperatur ist 20 Grad. |
| der Grad | degree | Es sind 25 **Grad**. |
| die Sonne | sun | Die **Sonne** scheint. |
| der Regen | rain | Ich habe Angst vor **dem** Regen. |
| der Schnee | snow | **Der** Schnee ist schon geschmolzen. |
| der Wind | wind | **Der** Wind ist stark. |
| die Wolke | cloud | **Die** Wolken sind dunkel. |
| der Sturm | storm | **Der** Sturm kommt bald. |
| das Gewitter | thunderstorm | **Das** Gewitter ist gefährlich. |
| bewölkt | cloudy | Heute ist es **bewölkt**. |
| sonnig | sunny | Morgen wird es **sonnig**. |
| regnerisch | rainy | Die Woche ist **regnerisch**. |
| windig | windy | Draußen ist es **windig**. |
| frostig | frosty | Im Winter ist es **frostig**. |
| kühl | cool | Im Herbst ist es **kühl**. |
| warm | warm | Im Sommer ist es **warm**. |

### Weather sentences

| German | English |
| --- | --- |
| Wie ist das Wetter heute? | How is the weather today? |
| Es regnet. | It is raining. |
| Es schneit. | It is snowing. |
| Die Sonne scheint. | The sun is shining. |
| Es ist bewölkt. | It is cloudy. |
| Morgen wird es wärmer. | Tomorrow it will get warmer. |
| Am Wochenende wird es sonnig. | At the weekend it will be sunny. |
| Die Temperatur sinkt auf 5 Grad. | The temperature drops to 5 degrees. |

## 3. Termine - Appointments

| German | English | Example |
| --- | --- | --- |
| der Termin | appointment | Ich habe **einen** Termin. |
| die Verabredung | appointment/date | Ich habe **eine** Verabredung. |
| die Einladung | invitation | Ich habe **eine** Einladung bekommen. |
| der Tag | day | Welcher **Tag** passt Ihnen? |
| die Woche | week | Nächste **Woche** ist gut. |
| das Wochenende | weekend | Am **Wochenende** habe ich Zeit. |
| die Uhrzeit | time (clock) | Um welche **Uhrzeit**? |
| der Vormittag | morning (before noon) | Am **Vormittag** bin ich frei. |
| der Nachmittag | afternoon | Am **Nachmittag** arbeite ich. |
| der Abend | evening | Am **Abend** treffen wir uns. |
| die Mittagspause | lunch break | In der **Mittagspause** esse ich. |

### Appointment verbs

| German | English | Example |
| --- | --- | --- |
| einen Termin vereinbaren | to make an appointment | Ich vereinbare einen Termin. |
| absagen | to cancel | Ich muss absagen. |
| verschieben | to postpone | Können wir verschieben? |
| um die Uhrzeit bitten | to ask about the time | Um wie viel Uhr? |
| zu spät kommen | to be late | Ich komme zu spät. |
| pünktlich sein | to be on time | Ich bin pünktlich. |
| warten auf + Akk | to wait for | Ich warte auf dich. |
| sich entschuldigen | to apologize | Ich entschuldige mich für die Verspätung. |

### Appointment sentences

| German | English |
| --- | --- |
| Können wir uns morgen treffen? | Can we meet tomorrow? |
| Wann passt es dir? | When suits you? |
| Um wie viel Uhr? | At what time? |
| Ich habe morgen um 10 Uhr einen Termin. | I have an appointment tomorrow at 10. |
| Können wir auf Donnerstag verschieben? | Can we postpone to Thursday? |
| Tut mir leid, ich muss absagen. | Sorry, I have to cancel. |
| Ich komme 10 Minuten zu spät. | I am 10 minutes late. |
| Entschuldigen Sie die Verspätung. | Sorry for the delay. |

!!! tip "Chunk to memorize"
    *Können wir uns morgen um 10 Uhr treffen?* / *Tut mir leid, ich muss absagen.*
