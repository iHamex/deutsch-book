# School and Education (A2)

> A2 vocabulary for 2 telc themes: Schule/Ausbildung/Weiterbildung, Berufswünsche, Kinderbetreuung.

---

## 1. Schule und Ausbildung

| German | English | Example |
| --- | --- | --- |
| die Schule | school | Ich gehe **zur** Schule. |
| die Universität | university | Er studiert **an der** Universität. |
| die Hochschule | college/university | Sie geht **auf die** Hochschule. |
| die Weiterbildung | further education | Ich mache **eine** Weiterbildung. |
| der Kurs | course | Ich besuche **einen** Deutschkurs. |
| die Prüfung | exam | Ich habe **eine** Prüfung. |
| die Note | grade | Ich habe **eine** gute Note. |
| die Hausaufgabe | homework | Ich mache **meine** Hausaufgaben. |
| das Referat | presentation | Ich halte **ein** Referat. |
| die Gruppenarbeit | group work | Wir machen **Gruppenarbeit**. |
| der Lehrer | teacher | Mein **Lehrer** ist nett. |
| die Lehrerin | teacher (f) | Meine **Lehrerin** hilft mir. |
| der Schüler | student (school) | Er ist **ein** guter Schüler. |
| die Schülerin | student (f) | Sie ist **eine** gute Schülerin. |
| der Student | student (university) | Er ist **Student**. |
| die Studentin | student (f) | Sie ist **Studentin**. |
| der Abschluss | degree/qualification | Ich mache **einen** Abschluss. |
| das Zeugnis | certificate/report card | Ich bekomme **mein** Zeugnis. |

## 2. Berufswünsche - Career Goals

| German | English | Example |
| --- | --- | --- |
| der Berufswunsch | career wish | Mein **Berufswunsch** ist Ingenieur. |
| der Traumberuf | dream job | Mein **Traumberuf** ist Arzt. |
| die Berufsausbildung | vocational training | Ich mache **eine** Berufsausbildung. |
| das Praktikum | internship | Ich mache **ein** Praktikum. |
| die Bewerbung | application | Ich schreibe **eine** Bewerbung. |
| der Arbeitsplatz | workplace | Ich suche **einen** Arbeitsplatz. |
| die berufliche Perspektive | career perspective | Die **berufliche Perspektive** ist gut. |

### Career sentences

| German | English |
| --- | --- |
| Was wollen Sie werden? | What do you want to become? |
| Ich möchte Ingenieur werden. | I want to become an engineer. |
| Ich studiere Informatik. | I study computer science. |
| Ich mache eine Ausbildung zum... | I am doing training to become... |
| Mein Traumberuf ist... | My dream job is... |
| Ich suche einen Arbeitsplatz. | I am looking for a workplace. |

## 3. Kinderbetreuung - Childcare

| German | English | Example |
| --- | --- | --- |
| der Kindergarten | kindergarten | Das Kind geht **in den** Kindergarten. |
| die Kita | daycare | Das Kind ist **in der** Kita. |
| die Grundschule | primary school | Das Kind geht **auf die** Grundschule. |
| die Oberschule | secondary school | Das Kind geht **auf die** Oberschule. |
| die Schulpflicht | compulsory education | In Deutschland gibt es **Schulpflicht**. |
| das Hort | after-school care | Das Kind ist **im** Hort. |
| die Ferien | holidays | In den **Ferien** bin ich zu Hause. |
| das Schuljahr | school year | Das **Schuljahr** beginnt im August. |
| das Halbjahr | half-year | Im **Halbjahr** gibt es einen Bericht. |

### Childcare sentences

| German | English |
| --- | --- |
| Mein Kind geht in den Kindergarten. | My child goes to kindergarten. |
| Wer betreut die Kinder? | Who takes care of the children? |
| Meine Kinder sind in der Kita. | My children are in daycare. |
| In Deutschland ist Schulpflicht. | In Germany there is compulsory education. |
| Meine Kinder haben Ferien. | My children have holidays. |

    *Ich möchte Ingenieur werden.* / *Mein Kind geht in den Kindergarten.*

- [ ] Schule: Kurs, Prüfung, Note, Hausaufgaben, Referat, Zeugnis.
