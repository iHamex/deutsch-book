## 2. Scoring breakdown

| Part | What counts | What you need |
| --- | --- | --- |
| Hören | listening tasks | Listen for keywords, write digits |
| Lesen | reading tasks | Scan for keywords, match |
| Schreiben | Formular + Brief | Fill boxes, write ca. 40 words |
| Sprechen | 3 Teile zu zweit | Introduce, talk, plan together |
| **Total** | all parts combined | **Pass = 36 of 60 (60%)** |

!!! warning "No per-part minimum"
    There is no minimum per part - you can fail one part and still pass if the others are strong. The total of 60 points needs 36 to pass. Train every part anyway.

> The exact raw-point split per task is shown in the official telc Übungstest solutions - use those when you score yourself.

## 4. Common mistakes - avoid these

| Mistake | Why it costs points | Fix |
| --- | --- | --- |
| leaving boxes empty | 0 points per empty box | ALWAYS write something |
| writing words instead of digits | slower, spelling errors | Write 8:00, not "acht Uhr" |
| one-sentence opinions | incomplete | Always: Ich finde..., denn... |
| not asking partner questions | one-sided conversation | Ask: Was denken Sie? |
| reading word by word | too slow | Scan for keywords |
| mixing immer/nie/nur traps | wrong answers | Read carefully: one exception = falsch |
| writing too much in Brief | wastes time, errors | 40 words = enough |
| forgetting Anrede/Gruß | missing structure | Sehr geehrte... / Mit freundlichen Grüßen |
