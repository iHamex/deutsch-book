# Hören Survival (telc A2)

> Hören has 3 Teile, ca. 20 minutes. Write digits, not words. Listen for KEY words. Train: Telefonansagen, Radio-Infos, Gespräche.

---

## Teil 1 - Telefonansagen + Notizen

### What happens
You hear phone messages and announcements. Write down names, numbers, times, addresses.

### Strategy
1. Read the questions BEFORE the audio starts.
2. Write DIGITS, not words (8:00, not "acht Uhr").
3. Listen for KEY words: Termin, Montag, Nummer, Uhr.
4. The audio is played TWICE. Write during first, check during second.

### What to listen for

| Keyword | What it means | Example |
| --- | --- | --- |
| Termin | appointment | "Am Montag um 10 Uhr" |
| Name | who | "Mein Name ist Weber" |
| Nummer | number | "Meine Nummer ist 089..." |
| Adresse | address | "Erika-Mann-Straße 12" |
| Uhrzeit | time | "Um halb drei" |
| Rückruf | callback | "Bitte rufen Sie mich zurück" |

!!! danger "Write digits, not words"
    Write "8:00" not "acht Uhr". Write "089/12345" not "null-acht-neun...". Digits are faster and risk-free.

## Teil 2 - Radio-Infos / Ansagen

### What happens
You hear radio announcements or public announcements. Match each to the right picture/statement.

### Strategy
1. Read the pictures/statements first.
2. Listen for WHERE, WHEN, WHAT, WHO.
3. Match: one keyword = one answer.
4. Audio is played TWICE.

### Common announcement topics

| Topic | Keywords to listen for |
| --- | --- |
| Wetter | sonnig, regnerisch, Temperatur, Grad |
| Verkehr | Verspätung, Stau, umsteigen, Gleis |
| Veranstaltung | Konzert, Theater, Eintritt, kostenlos |
| Gesundheit | Grippe, Impfung, Apotheke, Arzt |
| Bildung | Kurs, Anmeldung, Kosten, Beginn |

### Train your ear - Durchsagen (announcements)

Read each announcement aloud like a station speaker, then answer the question under it.

1. "Der Zug nach München fährt heute von Gleis 5 ab und hat 15 Minuten Verspätung." - Which platform? How much delay?
2. "Achtung, meine Damen und Herren, der Anschlusszug nach Berlin wartet auf Gleis 3." - What is waiting and where?
3. "Reisende nach Hamburg, bitte einsteigen! Der Zug fährt in zwei Minuten ab." - Which town? How much time?
4. "Nächster Halt: Hauptbahnhof. Bitte denken Sie an Ihre Gepäckstücke." - What is the next stop?
5. "Diese Bahn endet hier. Bitte steigen Sie aus." - What must you do?

??? success "Antworten - expand to check"

    1. Gleis 5, 15 Minuten Verspätung.
    2. Der Anschlusszug nach Berlin - Gleis 3.
    3. Hamburg - in zwei Minuten.
    4. Hauptbahnhof.
    5. Aussteigen (die Bahn endet hier).

## Teil 3 - Längeres Gespräch

### What happens
You hear a longer conversation. Answer richtig/falsch or multiple choice.

### Strategy
1. Read the questions first.
2. Listen for OPINIONS, DECISIONS, REASONS.
3. Mark "richtig" ONLY if the text says it exactly.
4. Watch for: aber, trotzdem, leider, eigentlich - these change the meaning.

### Trap words

| Trap | Example | Why it's a trap |
| --- | --- | ---|
| **aber** | Ich would like, aber... | The "aber" reverses the meaning |
| **trotzdem** | Es ist teuer, trotzdem... | Despite the problem, they still do it |
| **leider** | Leider kann ich nicht. | Unfortunately = NO |
| **eigentlich** | Eigentlich wollte ich... | Actually I wanted to = but I didn't |

!!! danger "richtig = text says it exactly"
    If the text doesn't mention it or says the opposite, it's falsch. "Nicht erwähnt" = falsch.
