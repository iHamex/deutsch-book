# Partizipien as Adjectives - Compact Description (A2, Receptive-Active)

> Participles can work as adjectives before nouns: der lachende Mann (the laughing man), das gekaufte Buch (the bought book). At A2 you understand them everywhere and build the common ones yourself.

---

## 1. Partizip I - the -d form (ongoing action)

Formation: Infinitiv + **-d**: lachen -> lachend, weinen -> weinend, kommen -> kommend.

| Example | English |
| --- | --- |
| der **lachende** Mann | the laughing man |
| das **weinende** Kind | the crying child |
| die **kommende** Woche | the coming week (next week) |
| ein **fahrender** Zug | a moving train |
| die **folgende** Woche | the following week |
| eine **passende** Antwort | a fitting answer |
| die **führende** Rolle | the leading role |
| eine **lebende** Legende | a living legend |

Meaning is always ACTIVE and ONGOING: the man who laughs right now, the train that moves right now.

!!! tip "The ones you already own"
    die **kommende** Woche = next week. die **folgende** Woche = the following week. Use both freely - they are pure A2 vocabulary.

Partizip I also works adverbially (how someone does something):

- Er kam **weinend** nach Hause. (He came home crying.)
- **Lachend** verließ sie das Zimmer. (Laughing, she left the room.)

!!! tip "Chunk to memorize"
    *Die kommende Woche habe ich Urlaub.* (Next week I have holiday.) / *Er kam weinend nach Hause.* (He came home crying.)

---

## 2. Partizip II - the -t/-en form (finished action)

Formation: the same Partizip II you know from Perfekt: gekauft, geschrieben, gebrochen.

| Example | English |
| --- | --- |
| das **gekaufte** Buch | the bought book |
| der **geschriebene** Brief | the written letter |
| das **gebratene** Fleisch | the fried meat |
| die **verlorene** Tasche | the lost bag |
| ein **erfahrener** Fahrer | an experienced driver |
| ein **gebrochenes** Bein | a broken leg |
| die **gestohlene** Tasche | the stolen bag |
| ein **reservierter** Tisch | a reserved table |
| ein **belegtes** Brötchen | a topped roll (sandwich) |

Meaning is usually PASSIVE and FINISHED: the book that was bought, the letter that was written.

!!! tip "Chunk to memorize"
    *Das gekaufte Buch ist interessant.* (The bought book is interesting.) / *Ein erfahrener Fahrer.* (An experienced driver.)

---

## 3. Endings follow normal adjective rules

Participles decline exactly like adjectives (see A1 adjective endings and A2 Part 03):

| Article | Example | English |
| --- | --- | --- |
| der-word | der lachende Mann / das gekaufte Buch | the laughing man / the bought book |
| ein-word | ein lachender Mann / ein gekauftes Buch | a laughing man / a bought book |

- Mit einem **lachenden** Kind spielt man gern. (dative -en, like every adjective)
- Die **kommende** Woche habe ich Urlaub.

---

## 4. Direct contrast - same stem, ongoing vs finished

| Partizip I (ongoing) | Partizip II (finished) | English |
| --- | --- | --- |
| die **steigenden** Preise | die **gestiegenen** Preise | the rising prices / the risen prices |
| die **folgende** Woche | die **vergangene** Woche | the following week / the past week |
| der **fahrende** Zug | der **gefahrene** Kilometer | the moving train / the driven kilometer |

!!! warning "Read the ending, not just the stem"
    steigenden vs gestiegenen differ by ONE syllable (ge-) and flip the meaning from ongoing to finished. In Lesen this distinction is a classic trap.

## 6. Cheat sheet

| Job | Form | Example | English |
| --- | --- | --- | --- |
| ongoing + active | Infinitiv + -d | der lachende Mann | the laughing man |
| finished (+ passive) | Partizip II | das gekaufte Buch | the bought book |
| endings | normal adjective declension | ein lachender Mann | a laughing man |

- [ ] Partizip I = -d, active, ongoing.
- [ ] Partizip II as adjective = finished (often passive).
- [ ] Endings follow the adjective table you already know.
