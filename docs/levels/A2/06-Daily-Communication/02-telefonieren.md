# Phone Calls (A2)

> At A1 you learned basic phone phrases. At A2 you handle answering machines, leave messages, make/shift appointments, and complain by phone.

---

## 1. Anruf starten - Starting a call

| Situation | German | English |
| --- | --- | --- |
| answering | Ja, hier ist... / Müller, guten Tag! | Yes, this is... / Müller, good day! |
| asking for someone | Ist Herr/Frau... da? / Kann ich mit... sprechen? | Is Mr./Ms... there? / Can I speak with...? |
| introducing yourself | Hier spricht... / Mein Name ist... | This is... / My name is... |
| reason for calling | Ich rufe wegen... an. / Ich möchte... | I am calling about... / I would like... |
| asking to hold | Einen Moment, bitte. / Können Sie kurz warten? | One moment, please. / Can you wait briefly? |
| put through | Ich verbinde Sie. / Einen Moment, ich hole sie. | I'll connect you. / One moment, I'll get her. |

## 2. Anrufbeantworter - Answering machine

| Situation | German | English |
| --- | --- | --- |
| greeting | Hier ist... / Sie haben den Anrufbeantworter erreicht. | This is... / You have reached the answering machine. |
| leave message | Bitte hinterlassen Sie eine Nachricht. | Please leave a message. |
| leaving message | Hier spricht... / Mein Name ist... Ich rufe wegen... an. | This is... / My name is... I am calling about... |
| callback | Bitte rufen Sie mich zurück. / Ich rufe später nochmal an. | Please call me back. / I'll call again later. |
| phone number | Meine Telefonnummer ist... / Sie erreichen mich unter... | My phone number is... / You can reach me at... |

### Answering machine message (copy this)

> Hier spricht Hamed Okhovvat. Tut mir leid, ich bin gerade nicht da. Bitte hinterlassen Sie eine Nachricht mit Ihrem Namen und Ihrer Telefonnummer. Ich rufe Sie zurück. Vielen Dank.

## 3. Termine machen/verschieben - Making/shifting appointments

| Situation | German | English |
| --- | --- | --- |
| ask for appointment | Können wir einen Termin vereinbaren? | Can we make an appointment? |
| suggest time | Wäre Montag um 10 Uhr möglich? | Would Monday at 10 be possible? |
| accept | Das passt mir gut. / Das ist in Ordnung. | That suits me well. / That's fine. |
| decline | Das passt mir leider nicht. / Da habe ich leider keinen Termin. | Unfortunately that doesn't suit me. / I don't have an appointment then. |
| suggest alternative | Geht auch Donnerstag? / Wäre Mittwoch besser? | Does Thursday work too? / Would Wednesday be better? |
| postpone | Können wir verschieben? / Ich muss leider verschieben. | Can we postpone? / Unfortunately I have to postpone. |
| cancel | Ich muss leider absagen. / Können wir absagen? | Unfortunately I have to cancel. / Can we cancel? |

## 4. Beschwerde - Complaint

| Situation | German | English |
| --- | --- | --- |
| start complaint | Ich habe ein Problem mit... | I have a problem with... |
| explain | Das funktioniert nicht. / Das ist kaputt. | That doesn't work. / That's broken. |
| demand | Können Sie das reparieren? / Ich möchte das umtauschen. | Can you repair that? / I'd like to exchange that. |
| money back | Ich möchte mein Geld zurück. | I want my money back. |
| threaten | Ich muss einen anderen Anbieter suchen. | I have to find another provider. |
| polite ending | Können Sie sich darum kümmern? / Wann ist es soweit? | Can you take care of it? / When will it be done? |

## 6. Model call - make an appointment (Sprechen + real life)

!!! example "Calling the doctor's office"
    - "Praxis Dr. Weber, guten Tag. Frau Schmidt am Apparat."
    - "Guten Tag, hier ist Hamed Okhovvat. Ich möchte gern einen Termin."
    - "Was fehlt Ihnen denn?"
    - "Ich habe seit drei Tagen Kopfschmerzen. Hätten Sie diese Woche etwas frei?"
    - "Einen Moment, bitte. Am Donnerstag um 10 Uhr wäre es möglich."
    - "Das passt mir gut. Vielen Dank!"
    - "Gern. Wir sehen uns am Donnerstag. Auf Wiederhören!"

!!! example "Leaving a message on the answering machine"
    - "Hier spricht Hamed Okhovvat. Ich rufe wegen meiner Bestellung an. Sie erreichen mich unter 0151 23456789. Ich rufe morgen noch einmal an. Vielen Dank!"

## 8. Cheat sheet

| Situation | Phrase | English |
| --- | --- | --- | --- |
| start a call | Hier ist Hamed. Kann ich bitte mit Frau Weber sprechen? | This is Hamed. Can I speak to Mrs Weber, please? |
| answer | Einen Moment, bitte. / Sie ist leider nicht da. | One moment, please. / She is unfortunately not here. |
| leave a message | Kann ich eine Nachricht hinterlassen? | Can I leave a message? |
| answering machine | Bitte hinterlassen Sie eine Nachricht nach dem Signalton. | Please leave a message after the tone. |
| appointment | Ich möchte einen Termin machen/verschieben. | I would like to make/reschedule an appointment. |
| complaint | Ich habe eine Beschwerde. | I have a complaint. |
| wrong number | Falsch verbunden. | Wrong number. |
| ending | Auf Wiederhören! | Goodbye (on the phone). |

- [ ] Identify yourself: Hier ist ... (not Ich bin ...).
- [ ] Ask: Kann ich bitte mit ... sprechen?
- [ ] End the call with Auf Wiederhören (not Auf Wiedersehen).
