# Extended Doctor, Bank, and Office Talks (A2)

> At A1 you learned survival chunks. At A2 you hold longer conversations at the doctor, bank, and government office - describing problems, asking questions, and understanding responses.

---

## 1. Arzt - Extended conversation

### Describing symptoms

| German | English |
| --- | --- |
| Mir tut der Kopf weh. | My head hurts. |
| Ich habe seit drei Tagen Kopfschmerzen. | I have had headaches for three days. |
| Mir ist übel. | I feel nauseous. |
| Ich habe Fieber seit gestern. | I have had fever since yesterday. |
| Mein Bauch krampft. | My stomach cramps. |
| Ich habe Appetitlosigkeit. | I have loss of appetite. |
| Mein Rücken schmerzt. | My back hurts. |
| Ich kann nicht schlafen. | I cannot sleep. |

### Understanding the doctor

| German | English |
| --- | --- |
| Öffnen Sie bitte den Mund. | Please open your mouth. |
| Atmen Sie bitte tief ein. | Please breathe in deeply. |
| Drücken Sie hier. Does it hurt? | Press here. Does it hurt? |
| Sie haben eine Erkältung. | You have a cold. |
| Sie müssen Bettruhe halten. | You must stay in bed. |
| Ich gebe Ihnen ein Rezept. | I give you a prescription. |
| Kommen Sie in einer Woche wieder. | Come back in one week. |
| Das ist nichts Schlimmes. | That is nothing serious. |

## 2. Bank - Extended conversation

### Opening an account

| German | English |
| --- | --- |
| Ich möchte ein Girokonto eröffnen. | I would like to open a checking account. |
| Welche Dokumente brauche ich? | Which documents do I need? |
| Hier ist mein Personalausweis. | Here is my ID card. |
| Welche Gebühren gibt es? | What fees are there? |
| Gibt es eine Mindesteinlage? | Is there a minimum deposit? |
| Brauche ich eine EC-Karte? | Do I need a debit card? |

### Transactions

| German | English |
| --- | --- |
| Ich möchte 500 Euro abheben. | I would like to withdraw 500 euros. |
| Können Sie eine Überweisung an... machen? | Can you make a transfer to...? |
| Wie hoch ist mein Kontostand? | What is my account balance? |
| Ich möchte einen Dauerauftrag einrichten. | I would like to set up a standing order. |
| Kann ich überziehen? | Can I overdraw? |
| Was kostet eine Überweisung ins Ausland? | What does a transfer abroad cost? |

## 3. Amt - Extended conversation

### Anmeldung (Registration)

| German | English |
| --- | --- |
| Ich möchte mich anmelden. | I would like to register. |
| Ich bin am... hier angekommen. | I arrived here on... |
| Hier ist mein Reisepass und meine Meldebescheinigung. | Here is my passport and registration certificate. |
| Wo wohnen Sie? | Where do you live? |
| Ich wohne in der... Straße. | I live in... street. |
| Wie lange dauert das? | How long does that take? |
| Wann kann ich die Bescheinigung abholen? | When can I pick up the certificate? |

### other Amt conversations

| German | English |
| --- | --- |
| Ich brauche eine Meldebescheinigung. | I need a registration certificate. |
| Ich möchte meinen Aufenthaltstitel verlängern. | I would like to extend my residence permit. |
| Welche Formulare muss ich ausfüllen? | Which forms do I have to fill out? |
| Muss ich eine Gebühr zahlen? | Do I have to pay a fee? |
| Wie lange ist das gültig? | How long is that valid? |
| Kann ich das per Post bekommen? | Can I receive that by post? |

!!! tip "Chunk to memorize"
    *Ich möchte mich anmelden.* / *Hier ist mein Personalausweis.* / *Wie lange dauert das?*

## 4. Model dialogue - beim Arzt (at the doctor)

!!! example "Sprechstunde"
    - "Guten Tag, Herr Okhovvat. Was fehlt Ihnen?"
    - "Mir tut der Kopf weh, und ich habe seit gestern Fieber."
    - "Seit wann genau? Und schlafen Sie gut?"
    - "Seit drei Tagen fühle ich mich schlecht. Ich kann nachts nicht schlafen."
    - "Atmen Sie bitte tief ein. Ja, das ist eine Erkältung. Ich gebe Ihnen ein Rezept."
    - "Soll ich in der Apotheke etwas holen?"
    - "Ja, das Medikament gibt es dort. Kommen Sie in einer Woche wieder, wenn es nicht besser ist."
    - "Vielen Dank. Auf Wiedersehen!"

---

## 5. Model dialogue - auf der Bank (at the bank)

!!! example "Konto eröffnen"
    - "Guten Tag, ich möchte gern ein Girokonto eröffnen."
    - "Gern. Welche Dokumente haben Sie dabei?"
    - "Hier ist mein Personalausweis und meine Anmeldebescheinigung."
    - "Das reicht schon. Und welche Gebühren gibt es?"
    - "Das Konto ist kostenlos. Sie bekommen eine EC-Karte per Post."
    - "Kann ich später auch überweisen?"
    - "Natürlich, online oder hier am Schalter. Möchten Sie auch eine Kreditkarte?"
    - "Nein, danke, das ist nicht nötig."

---

## 6. Model dialogue - im Amt (at the office)

!!! example "Anmeldung"
    - "Guten Tag, ich möchte mich anmelden. Ich bin am Montag hier angekommen."
    - "Willkommen in München. Wo wohnen Sie?"
    - "Ich wohne in der Erika-Mann-Straße 12."
    - "Haben Sie Ihren Reisepass und das Formular?"
    - "Ja, hier bitte. Welche Gebühr muss ich zahlen?"
    - "Die Anmeldung ist kostenlos. Sie bekommen die Bescheinigung in drei Tagen per Post."
    - "Kann ich sie auch abholen?"
    - "Ja, das geht auch. Fragen Sie am Schalter 3."
