# Complaints and Consultation (A2)

> At A2 you complain politely and get what you need: refund, repair, appointment. You use Konjunktiv II for politeness: Ich hätte gern, Würden Sie, Könnten Sie...

---

## 1. Reklamation - Complaint

| Situation | German | English |
| --- | --- | --- |
| start complaint | Ich habe ein Problem mit... | I have a problem with... |
| explain problem | Das funktioniert nicht. / Das ist kaputt. | That doesn't work. / That's broken. |
| show receipt | Ich habe die Quittung. / Hier ist die Rechnung. | I have the receipt. / Here is the bill. |
| demand repair | Können Sie das reparieren? | Can you repair that? |
| demand exchange | Ich möchte das umtauschen. | I would like to exchange that. |
| demand refund | Ich möchte mein Geld zurück. | I want my money back. |
| warranty | Die Garantie ist noch gültig. | The warranty is still valid. |
| polite ending | Können Sie sich darum kümmern? | Can you take care of it? |

### Polite complaint (with Konjunktiv II)

| German | English |
| --- | --- |
| Könnten Sie das bitte reparieren? | Could you please repair that? |
| Wären Sie so freundlich, das umzutauschen? | Would you be so kind as to exchange that? |
| Wäre es möglich, mein Geld zurückzubekommen? | Would it be possible to get my money back? |
| Dürfte ich bitte mit dem Manager sprechen? | Might I please speak with the manager? |

## 2. Beratung - Consultation

| Situation | German | English |
| --- | --- | --- |
| ask for advice | Können Sie mir helfen? / Was können Sie empfehlen? | Can you help me? / What can you recommend? |
| describe need | Ich suche... / Ich brauche... | I am looking for... / I need... |
| ask about price | Wie viel kostet das? / Was kostet das? | How much does that cost? |
| ask about quality | Ist das gut? / Wie ist die Qualität? | Is that good? / How is the quality? |
| compare | Gibt es etwas Besseres? / Haben Sie das auch in...? | Do you have something better? / Do you also have that in...? |
| decide | Ich nehme das. / Das passt mir gut. | I'll take that. / That suits me well. |
| ask about payment | Kann ich mit Karte zahlen? / Geht auch Barzahlung? | Can I pay by card? / Is cash also okay? |
| ask about return | Kann ich das zurückgeben? | Can I return that? |

### Polite consultation (with Konjunktiv II)

| German | English |
| --- | --- |
| Könnten Sie mir bitte helfen? | Could you please help me? |
| Was würden Sie empfehlen? | What would you recommend? |
| Hätten Sie das in einer anderen Farbe? | Would you have that in another color? |
| Wäre das möglich? | Would that be possible? |
| Dürfte ich das anprobieren? | Might I try that on? |

## 3. Arzt/Bank/Amt - Extended chunks

### Arzt

| German | English |
| --- | --- |
| Ich hätte gern einen Termin. | I would like an appointment. |
| Was fehlt Ihnen? | What is wrong with you? |
| Mir tut... weh. | My... hurts. |
| Seit wann haben Sie das? | Since when do you have that? |
| Können Sie mir ein Rezept geben? | Can you give me a prescription? |

### Bank

| German | English |
| --- | --- |
| Ich möchte ein Konto eröffnen. | I would like to open an account. |
| Wie viel möchten Sie abheben? | How much would you like to withdraw? |
| Können Sie eine Überweisung machen? | Can you make a transfer? |
| Wie hoch ist mein Kontostand? | What is my account balance? |

### Amt

| German | English |
| --- | --- |

## 4. Model dialogue - complain in the shop (Reklamation)

!!! example "The coffee machine is broken"
    - "Guten Tag, ich habe ein Problem mit dieser Kaffeemaschine. Sie funktioniert nicht mehr."
    - "Haben Sie die Quittung?"
    - "Ja, hier ist die Rechnung. Ich habe sie vor zwei Wochen gekauft."
    - "Die Garantie ist noch gültig. Wir können sie reparieren oder umtauschen."
    - "Könnten Sie sie bitte reparieren? Das wäre mir am liebsten."
    - "Gut, das dauert etwa eine Woche. Wir rufen Sie an, wenn sie fertig ist."
    - "Vielen Dank. Können Sie sich bitte darum kümmern?"
    - "Selbstverständlich. Auf Wiedersehen!"

---

## 5. Model dialogue - consultation in the shop (Beratung)

!!! example "Buying a laptop"
    - "Guten Tag, ich suche einen Laptop für die Arbeit. Können Sie mir helfen?"
    - "Gern. Was ist Ihnen wichtig?"
    - "Ich brauche etwas Leichtes, denn ich reise viel. Was würden Sie empfehlen?"
    - "Dieses Modell hier ist sehr leicht und hat einen guten Akku."
    - "Wie viel kostet es? Und kann ich mit Karte zahlen?"
    - "Es kostet 799 Euro. Mit Karte ist kein Problem."
    - "Gut, ich nehme es. Kann ich es zurückgeben, wenn es nicht passt?"
    - "Ja, innerhalb von 14 Tagen."

## 6. Practice - polite complaint and consultation

- I have a problem with this device.
- It does not work anymore.
- Here is the receipt.
- The warranty is still valid.
- Could you please repair that?
- I would like to exchange that.
- I would like my money back.
- Can I pay by card?
- What would you recommend?
- Would you have that in another color?
- Might I try that on?

??? success "Antworten - expand to check"

    1. Ich habe ein Problem mit diesem Gerät.
    2. Es funktioniert nicht mehr.
    3. Hier ist die Quittung.

    8. Kann ich mit Karte zahlen?
