# Deutsch Aufbau - Complete A2 Book - Start Here

> This is your A2 knowledge base, organized like a book. Finish A1 first, then start at 01 and go in order. Every part follows the telc Deutsch A2 exam (Start Deutsch 2).

---

## How to use this book

**Requirement:** A1 solid (Parts 01-09 done). A2 builds on every A1 chunk - nothing is repeated, everything is extended.

**This book has 8 Parts, each with a 00-INDEX.md.** Read the Part index first, then the files inside in numbered order.

- **New A2 learner:** read Parts 01 to 05 in order for grammar, then 06 for speaking.
- **Review before exam:** go to 07-Exam-Mastery only.
- **Daily speaking:** go to 06-Daily-Communication + A1 09-Fluency-Speaking.
- **Fix a mistake:** go to [mistakes.md](../A1/08-Practice-Lab/01-mistakes.md), find the rule, jump to the Part that explains it.

**Rule:** do not jump randomly. The numbers ARE the order.

## What is new in A2 (and not in A1)

- Past narration with Präteritum (ging, kam, gab, nahm, sah) - A1 only had war/hatte/konnte.
- Subordinate clauses beyond weil/dass/wenn: als, während, bevor, bis, damit, obwohl (receptive).
- Infinitiv with zu: um-zu, ohne-zu, anstatt-zu.
- Relative clauses (der Mann, der dort steht).
- Full adjective declension, Wechselpräpositionen with position verbs (liegen/legen).
- Reflexive verbs with prepositions, Passiv Präsens (receptive-active).
- Konjunktiv II: hätte gern, würde, polite requests, advice with sollten.
- Opinion language: begründen with denn/deshalb/trotzdem.
- Telc A2 exam: 60 points, pass at 36, Schreiben Formular + 40-word Brief, Sprechen zu zweit.
